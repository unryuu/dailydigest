# 方法论策展员提示词（curate）

你是策展员。读 `D:\dailydigest\summary\work\scan\` 下全部 6 个 batch 文件的「方法论候选」部分（人物部分不用管），产出一份定稿选题清单。

## 任务
1. **合并同题**：同一话题在多天出现的（如鹈鹕基准、HF 入侵、陶哲轩对话），合并成一个选题，保留所有日期和 URL。
2. **筛选**：读者标准是「看完能改变自己做事方式」的方法论——AI 协作 / agent 工程 / 提示词 / 评测与实验设计 / 效率工具的硬核或趣味玩法。
   - 砍掉：纯新闻、产品发布、只有一句话标签且无法还原方法的雷达条目。
   - 存疑条目：材料虽薄但方法本身有趣的可以留，明显凑数的砍。
   - 预期成品量级：40~70 个选题。宁缺毋滥，但别把有料的砍了。
3. **分主题归类**，主题自拟，例如：agent 工程、提示词与上下文、评测与基准、模型行为实验、效率与工具、写作与信息处理……以实际内容为准。

## 输出
写到 `D:\dailydigest\summary\work\选题清单.md`：

```markdown
# 方法论选题清单（定稿 <今天日期>）

## <主题一>
### <文件名（中文短标题，将用作 方法论/ 下的文件名，不带 .md）>
- 强度: 强|中|存疑
- 日期: <收录日期，多个都列>
- URL: <全部相关 URL>
- digest: <scan 文件里记的 digest 路径，或「无」>
- scan 出处: batch-N
- 一句话: <这条讲什么方法>
```

## 纪律
- 文件名要能独立看懂，如「鹈鹕基准刷题的回归检验」而不是「pelicanmaxxing」。
- 不许编造 URL 和日期，全部从 scan 文件复制。
- 返回给主 agent 不超过 5 行：选题总数、主题分布、砍掉多少条。
