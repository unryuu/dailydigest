# loop engineering 四分类：回合制、目标制、定时制、无人值守

- 日期：2026-07-02
- 来源：https://claude.com/blog/getting-started-with-loops
- 主题：一、agent 工程与 harness

## 这是什么

Claude Code 官方这篇不是新功能发布，更像把社媒上火起来的 loop engineering 收编成方法论。这个词此前由 Boris Cherny 和 Peter Steinberger 在社媒带火，一个月后官方把散落的玩法归成四类：turn-based 回合制、goal-based 目标达成才停、time-based 按时间间隔跑、proactive 无人值守触发。它的定义很朴素，就是 agent 重复一轮轮工作，直到满足停止条件。真正值得记的是官方主动踩刹车：不是所有任务都需要复杂循环，先用最简单方案，只在合适场景选择这些模式。也就是说，这篇别读成又一篇 `/loop` 或 `/schedule` 功能介绍，重点是一个社媒梗被厂商整理成正式分类学，同时被提醒不要过度工程。

## 可以怎么用

- 给一个重复性任务设计自动化流程前，先用这四类给自己定位：这是「跑几轮就该停」（回合制）、「直到达标才停」（目标制）、「按固定节奏跑」（定时制），还是「触发了才跑、平时不用管」（无人值守）——分类想清楚了，停止条件自然就清楚了。
- 官方的刹车提醒同样适用：先问这个任务是不是真的需要循环，能一次性做完的别硬套成循环结构，避免为了用工具而过度设计流程。
- 遇到别人讲「loop engineering」这类新词时，可以按这四分类快速判断对方说的具体是哪一种，不必被术语唬住。
