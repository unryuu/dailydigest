# 把验证过的解答存成 KV 缓存，遇同类题直接嫁接

- 日期：2026-07-19
- 来源：https://huggingface.co/papers/2607.14431（主文）
- 主题：六、模型行为与训练方法

## 这是什么

冻结的 12B 模型把验证过的解答存成缓存，遇到同类难题直接嫁接进上下文，AIME 从 80 涨到 93.3，重复难题 token 花销降几千倍。

## 可以怎么用

- 对于会反复遇到同类难题的场景（如固定题型的数学/代码问题），把已验证正确的解答存成 KV 缓存、遇到同类问题直接嫁接进上下文复用，比每次重新推理更省 token，还可能提升准确率。
- 这套思路不需要重新训练模型（冻结的模型即可），是一个纯推理侧、部署成本低的效率优化手段，值得在自己有稳定重复任务模式的场景里尝试。
- 关键前提是「解答已被验证过」，即缓存前先确认正确性，否则复用的可能是错误解法，反而放大错误。
