# 防背题基准：真实 commit 反向改写成口语化需求

- 日期：2026-07-24
- 来源：https://huggingface.co/papers/2607.20911
- 主题：四、评测与实验设计

## 这是什么

腾讯新基准 WorkBuddy Bench：让编码 agent 没法背题。260 道题全从真实 commit 反向改写成口语化需求，搜不到原题，所以敢全量公开。安全赛道两个榜第一都是开源的 GLM-5.2。

一句话：WorkBuddy Bench 把 260 道题从真实 commit 反写成口语需求，搜不到原题所以敢全量公开。

## 细节（来自精读摘要）

无。

## 可以怎么用

- 自己想做一个能公开分享、又不怕被「背题」污染的评测集，可以借鉴「从真实素材反向改写成口语化描述」这个思路——原始素材（如真实 commit）能查到，但改写后的表述搜不到，天然防止被搜索引擎/训练语料收录后失效。
- 判断一个公开基准是否可信，可以先问「这套题能不能被搜到原题」，搜得到的基准分数要打折扣看。
- 反向改写的做法也提示：评测设计时，「题目来源真实」和「题目表述不可搜索」这两个属性可以同时兼顾，不必二选一。
