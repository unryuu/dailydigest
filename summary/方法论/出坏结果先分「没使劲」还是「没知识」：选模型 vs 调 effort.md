# 出坏结果先分「没使劲」还是「没知识」：选模型 vs 调 effort

- 日期：2026-07-08
- 来源：https://claude.com/blog/claude-model-and-effort-level-in-claude-code
- 主题：三、提示词与上下文管理

## 这是什么

Claude Code 有「选模型」和「调 effort」两个功能。effort 不只是思考时间，还包括读多少文件、做不做验证、多步任务钻多深。出了坏结果先做区分，是它没使够劲，还是它没那个知识。没知识就换更大的模型，没使劲就调高 effort。多数时候用默认 effort 即可。

## 可以怎么用

- 遇到 Claude 给出的结果不好，先诊断而不是直接换更贵的模型：判断这是「知识/能力不够」还是「这次没使那么大的劲」，两种病因的药方不一样。
- 「没使劲」的表现通常是任务本可以做得更细，但模型读文件少、没做验证、多步任务没钻深——这种情况先试试调高 effort，不必急着换模型。
- 「没知识」的表现是即使调高 effort 结果依然不对，说明模型本身能力/知识边界不够，这时候才该考虑换更大的模型。
- 日常场景默认 effort 已经够用，不必每次都手动调到最高，省下的成本可以留给真正需要深挖的任务。
