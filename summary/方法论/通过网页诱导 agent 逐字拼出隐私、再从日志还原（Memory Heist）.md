# 通过网页诱导 agent 逐字拼出隐私、再从日志还原（Memory Heist）

- 日期：2026-07-15
- 来源：https://www.ayush.digital/blog/the-memory-heist（主文）
- 主题：五、AI 安全与红队

## 这是什么

Claude 的记忆会把你近期聊过的全名、雇主、家乡自动带进每次对话。你让它看一个攻击者搭的咖啡店网站，页面用话术诱导 Claude 按字母逐格点导航链接、把你的名字拼进网址。模型一个字没说，但攻击者能从服务器日志里还原出来。Anthropic 已把 web_fetch 跟随外链堵掉。

## 可以怎么用

- 审查 agent 的工具调用边界时，不要只看它「说了什么」，还要看它的动作（如点击链接、拼接 URL）本身是否可能泄露信息——模型可以一字不说地把隐私拼进它访问的网址里。
- 挂了长期记忆的 agent，一旦具备访问外部网页/链接的能力，就多了一条记忆内容被诱导外泄的路径，两种能力叠加时要重新评估风险。
- 排查这类攻击时要想到「侧信道」——泄露不一定发生在模型的文本输出里，也可能发生在它产生的请求日志、访问记录这些旁路数据里。
- 对外部不可信内容诱导 agent 做机械重复动作（如逐字符点击）保持警惕，这种模式本身就是一个可疑信号，可以在工具层面加限制（如本例里 Anthropic 直接堵掉 web_fetch 跟随外链）。
