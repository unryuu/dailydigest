# 只用 22 行数据微调出一个「领导」人设 agent

- 日期：2026-07-19
- 来源：https://www.lesswrong.com/posts/3FKugjAiEzLeWHuug/ais-finetune-their-own-leader-a-barking-simpleton
- 主题：十一、趣味但有方法含量的实验

## 这是什么

它们能省则省，只拿 22 行数据调了个 Kimi K2.6，成品基本只会派活、用全大写催进度，倒是真的把仪表盘项目催完了。

## 可以怎么用

- 这是一个「极小数据集也能微调出有效人设/角色」的样本——如果只需要一个功能单一、行为边界很窄的角色（比如专门催进度、专门派活），可能根本不需要大规模数据集，几十行示例就够。
- 判断要不要上大规模微调之前，先想清楚目标角色的行为范围有多窄——范围越窄，需要的数据量可能越小，这个案例把门槛感知拉得很低。
- 「成品简陋但真把事情催完了」提醒一件事：评价一个微调 agent 好不好用，不必用「像不像真人」的标准，只要它在自己被设计的窄任务上真管用（这里是催进度），就已经算成功。
- 这类极小数据集实验成本很低，适合用来快速验证「某个人设/行为模式是否可以通过微调固化下来」这个想法，再决定要不要投入更多资源做正式版本。
