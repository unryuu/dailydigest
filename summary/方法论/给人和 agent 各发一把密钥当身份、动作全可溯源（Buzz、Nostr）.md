# 给人和 agent 各发一把密钥当身份、动作全可溯源（Buzz、Nostr）

- 日期：2026-07-22
- 来源：https://runtimewire.com/article/jack-dorsey-block-buzz-team-chat-ai-agents-git（主文）
- 主题：五、AI 安全与红队

## 这是什么

Jack Dorsey 发布 Buzz：聊天、agent、Git 三合一，开源可自部署，想同时替代 Slack 和 GitHub。以 Nostr 协议作为底座，人和 agent 各拿一把密钥当身份；agent 是正式成员，能提补丁、审代码，每件事都能追溯到背后的主人。

## 可以怎么用

- 给团队里的 agent 分配和人一样的正式身份（一把密钥），而不是让它挂在某个人名下当隐形代理，这样 agent 的每个动作都能独立追溯，出问题不用先猜是人还是 agent 干的。
- 用密码学身份（而非账号密码）做 agent 的鉴权底座，能让「谁在什么时候做了什么」这件事本身可验证，不依赖平台方的日志诚实与否。
- 让 agent 具备提交补丁、审查代码这类正式成员权限时，配套的身份可溯源机制应该同步跟上，权限和可追责性要绑在一起设计，而不是先给权限、追责机制后补。
