# 自博弈强化学习训一个专职攻击模型（GPT-Red）

- 日期：2026-07-17
- 来源：https://openai.com/index/unlocking-self-improvement-gpt-red（主文）
- 主题：五、AI 安全与红队

## 这是什么

OpenAI 用自博弈强化学习训练了一个永不对外发布的攻击模型 GPT-Red：攻防两边同场对练，各自靠打穿对方和扛住攻击得分。测试里它攻破 84% 的场景，人类红队只有 13%，真把 OpenAI 办公室的 AI 售货机 agent 黑了。攻击喂进 GPT-5.6 训练后，直接注入失败率压到 0.05%。

## 可以怎么用

- 红队测试可以做成攻防两边自博弈对练打分的闭环，而不是单次人工渗透测试，规模化程度和攻破率都远超人类红队（84% vs 13%）。
- 攻击模型挖出来的真实攻击案例，直接喂回主模型做训练，能把已知攻击方式的失败率压到接近零（0.05%），是把红队产出直接转化成防御能力的具体路径。
- 专职攻击模型不对外发布,只在内部用来持续攻击自己的生产 agent（如内部售货机 agent），能发现真实场景里才会暴露的漏洞。
