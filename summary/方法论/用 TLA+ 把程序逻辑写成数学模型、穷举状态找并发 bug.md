# 用 TLA+ 把程序逻辑写成数学模型、穷举状态找并发 bug

- 日期：2026-07-04
- 来源：https://ubuntu.com/blog/hunting-a-16-year-old-sqlite-bug-with-tla-is-dqlite-affected
- 主题：七、AI 辅助研究与数学

## 这是什么

他们把程序逻辑写成数学模型、让电脑穷举所有情况，很快复现出了这个 SQLite 并发 bug。

## 可以怎么用

- 排查疑难并发 bug 时，与其反复靠肉眼读代码或加日志复现，不如把核心逻辑抽象成状态机模型，用穷举工具把所有状态组合都跑一遍，让机器帮你找到人脑难以想到的边界情形。
- 这种方法特别适合「复现概率低、条件苛刻」的并发问题——16 年都没被抓到的 bug，形式化建模能很快命中。
- 对自己维护的关键并发/分布式组件（锁、队列、状态同步逻辑），可以考虑把核心不变量写成简化模型，定期做一次穷举检验，而不是等出问题了才去查。
- 这类硬核验证法门槛不低，值得留意但不必事事都上——用在「一旦出错代价很大、又长期没找到根因」的地方最划算。
