# coding agent 让「不划算的逆向工程」变便宜

- 日期：2026-07-21
- 来源：https://simonwillison.net/2026/Jul/20/cheap-reverse-engineering/
- 主题：八、效率工具与本地模型

## 这是什么

以前不划算撬的家电私有接口，现在扔给 coding agent 顺手就干了。

## 可以怎么用

- 重新盘点一批以前因为「投入产出比不划算」而放弃的逆向工程/自动化小任务（家电私有协议、老旧系统接口、没文档的工具），现在成本结构变了，可能值得用 coding agent 重新试一次。
- 判断标准从「值不值得花时间学」变成「值不值得花几个 prompt 试一次」，门槛大幅降低，可以更随意地去试探这类边缘需求。
- 这类任务通常边界清晰（有明确的输入输出可验证），适合直接交给 agent 全权处理，不需要太多人工盯梢。
