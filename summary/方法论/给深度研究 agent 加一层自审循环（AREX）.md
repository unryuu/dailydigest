# 给深度研究 agent 加一层自审循环（AREX）

- 日期：2026-07-25
- 来源：https://huggingface.co/papers/2607.21461
- 主题：一、agent 工程与 harness

## 这是什么

找答案难、验答案容易——外层逐条核对约束，没查实的再打回去查。122B 稀疏版只激活 100 亿参数，BrowseComp 82.5%。

## 可以怎么用

- 设计需要深度研究/多步查证的 agent 流程时，可以套用「找答案难、验答案容易」这个不对称：让主流程负责生成候选答案，另开一层专门做「逐条核对约束是否满足」的自审循环，而不是指望一次生成就对。
- 自审循环发现某条约束没被查实时，直接把这条打回去重新查，而不是整体推倒重来——这样能把验证成本集中花在真正没查实的点上。
- 这个思路也能用在人工审核流程上：把最终产出拆成一条条可核对的约束/事实点，逐条核对比通读一遍更容易发现遗漏。
