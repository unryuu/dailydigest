# 长任务别只看成败：给中途进度打分

- 日期：2026-07-13
- 来源：https://huggingface.co/papers/2607.08964
- 主题：四、评测与实验设计

## 这是什么

Long-Horizon-Terminal-Bench：测 agent 长程终端任务的新基准。跟以往只看成没成不同，它给中途进度打分，发现六成多的运行其实有实质进展，只是走不到终点。

一句话：Long-Horizon-Terminal-Bench 给中途进度打分，发现六成多的运行其实有实质进展、只是走不到终点。

## 细节（来自精读摘要）

无。

## 可以怎么用

- 评估自己或团队用 agent 跑长任务的效果时，别只用「成功/失败」这个二元标准打分——很多「失败」的运行其实已经完成了大半有价值的工作，给中途进度打分能更准确地反映 agent 的真实产出。
- 如果一个长任务反复「失败」，先看看进度打分而不是直接判定 agent 不行——可能只是差最后一步，调整策略（比如分段验收、人工接手收尾）比推倒重来更划算。
- 这个思路可以迁移到评估自己的工作流程：长周期任务（写报告、做项目）也不该只看「完成了没有」，中途里程碑的进度同样值得追踪和记录。
