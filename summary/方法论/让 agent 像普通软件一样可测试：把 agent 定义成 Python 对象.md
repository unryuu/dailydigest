# 让 agent 像普通软件一样可测试：把 agent 定义成 Python 对象

- 日期：2026-07-26
- 来源：https://huggingface.co/papers/2607.20709
- 主题：一、agent 工程与 harness

## 这是什么

NVIDIA 新框架把 agent 作为原生 Python 对象。方法就是它能做的动作，字段就是它的状态，函数的注释就是提示词。如果一个方法的函数体，只写个省略号，运行时就交给大模型来完成；写了正常代码的方法，就还是运行代码。agent 的行为可以像普通软件一样测试、调试、重构。配 GPT-5.5 在 SWE-bench 上 82.2%。

## 可以怎么用

- 设计自己的 agent/工具时，可以借用这个「代码优先」的心法：能用确定性代码写清楚的步骤就写代码，只把真正需要模型判断的那一小段留白（相当于「函数体写省略号」），而不是整段逻辑都交给一句自然语言提示词。
- 把 agent 的「状态」显式建成字段（而不是散落在对话历史里），能让行为更容易复现、调试和单测，出问题时可以像排查普通代码 bug 一样定位到具体方法。
- 这个思路提醒我们：agent 工程和普通软件工程不必是两套方法论，凡是能用代码测试/重构的部分，就不必勉强留在纯提示词层面。
