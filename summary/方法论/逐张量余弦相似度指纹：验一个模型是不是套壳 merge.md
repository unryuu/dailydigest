# 逐张量余弦相似度指纹：验一个模型是不是套壳 merge

- 日期：2026-06-15
- 来源：https://github.com/nex-agi/Nex-N2/issues/4（主文）
- 主题：四、评测与实验设计

## 这是什么

里约热内卢市政府下属 IT 公司 IplanRIO 在 HuggingFace 发布了号称<b>自研</b>的 397B 原创大模型 Rio-3.5-Open。Nex-AGI 一个 GitHub issue 把它当场拆穿：根本不是训练的，而是 <b>Nex-N2-Pro 和 Qwen3.5 按约 0.6 / 0.4 比例做的逐张量加权 merge</b>。
证据硬到没法狡辩：① 去掉硬编码的「You are Rio」系统提示后，直接问底层权重「你是谁」，<b>79% 答 Nex、0% 答 Rio</b>，还逐字背出 Nex 私有的组织背书文案；② 权重层面，每层每个张量对 Nex/Qwen 的共线性高达 <b>0.99</b>（两个独立模型本应近乎正交、≈0），相当于离随机几千个标准差——任何人拿两个公开模型 + 一段脚本就能复现。
评论区那句钩子：开源权重是把双刃剑——<b>「你永远不会死，但你也藏不住偷窃，因为数学会记得。」</b>
被曝后 IplanRIO <b>悄悄改了 HF README 认账</b>是 merge 并致歉（称传错了版本）。仍未定论的两点：是否真做过蒸馏训练（口头声称、权重无痕迹），以及是否花了公款（市长发推说「用公共资金训练」，另有人称没花，口径打架）。

## 可以怎么用

- 怀疑一个「自研」模型其实是拿公开模型 merge 出来的，可以直接跑逐张量余弦相似度，独立训练的模型应接近正交（≈0），高共线性（≈0.99）就是实锤，不用等对方承认。
- 这个方法只需要两个公开模型的权重 + 一段脚本，成本极低，可以当成日常验证「某开源模型是否有猫腻」的标准动作。
- 去掉系统提示词后直接盘问模型「你是谁」，是识破套壳的一个廉价辅助手段——系统提示能装人设，权重装不了。
