# 陶哲轩用 coding agent 复活 1999 年搁置的旧工具

- 日期：2026-07-12
- 来源：https://terrytao.wordpress.com/2026/07/11/old-and-new-apps-via-modern-coding-agents/
- 主题：七、AI 辅助研究与数学

## 这是什么

是一批用 Java 写、后来因浏览器不再支持 Java 而失效的教学 applet。用 coding agent 移植成了 JavaScript，几小时搞定。移植里只找到一个小 bug，agent 反过来揪出了旧代码里两个他自己当年都不知道的 bug，代码质量算下来打平甚至更好。

他 1999 年就想做一个狭义相对论的时空图工具，当年动手写 Java 但代码复杂就放弃了，这次用 agent 边聊边写几个小时就做出来了。全程没点名用的是哪个模型。

## 可以怎么用

- 手头那些「因为技术栈过时而失效、但逻辑还在」的旧项目（老 applet、老脚本、老工具），可以扔给 coding agent 做语言/框架移植，成本比想象中低很多。
- 移植不只是省事，还可能是一次免费的代码审查——agent 在重写过程中顺手就会挑出原代码里自己都没意识到的 bug。
- 「当年觉得太复杂而放弃的项目」值得用现在的 agent 重新评估一次，门槛可能已经今非昔比。
- 边聊边写（对话式迭代）而不是一次性甩需求，是让 agent 处理这类模糊旧项目复活任务时更顺手的方式。
