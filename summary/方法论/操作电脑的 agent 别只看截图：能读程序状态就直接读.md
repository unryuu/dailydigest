# 操作电脑的 agent 别只看截图：能读程序状态就直接读

- 日期：2026-07-28
- 来源：https://huggingface.co/papers/2607.22798
- 主题：一、agent 工程与 harness

## 这是什么

截图只是程序状态的有损渲染，同样画面背后可能是不同状态。让操作电脑的 agent 用代码直接读写文件和后端，必须鼠标点击的时候才看画面。

## 可以怎么用

- 让 agent 操作某个软件/系统时，先看能不能直接读它的底层数据（文件、数据库、API 返回），而不是默认用截图 + 视觉理解去猜界面状态；截图应该是最后手段，只在必须模拟鼠标点击时才用。
- 排查「agent 明明照做了却出错」的问题时，可以怀疑是不是它靠截图误判了状态——同一张图背后可能对应不同的真实状态，视觉判断天然有损。
- 设计自己的 agent 工作流时，优先给它开一条能直接读程序状态的通道（哪怕只是一个只读接口），把截图/视觉识别限定在真正没有其他办法的场景。
