# 把运行日志本身当成 agent 的地基（The Log Is the Agent）

- 日期：2026-07-05
- 来源：https://arxiv.org/abs/2605.21997
- 主题：一、agent 工程与 harness

## 这是什么

以一份只增不改的操作日志为基底搭 agent，每一步都能精确重放、复盘。

## 可以怎么用

- 给自己的 agent/自动化流程设计记录方式时，优先用「只增不改」（append-only）的日志作为唯一真相来源，而不是把状态散落在会被覆盖的临时文件里，这样任何一步出问题都能精确回放定位。
- 复盘一次多步骤 agent 任务时，先确认有没有完整的只增日志；如果没有，等于失去了精确复盘的基础，下次该优先把日志补上。
- 这个思路也能反过来用在自己的工作流上：把每天/每期工作过程中的关键动作记成一份只增日志（而不是随时覆盖的状态文件），方便事后追溯哪一步出了问题。
