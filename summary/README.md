# summary —— 日报副产品：方法论与人物归纳

从 AI 日报历史产物（2026-06-12 ~ 07-29，46 期）里挖出来的、能应用到日常工作 / 值得写博客的东西。日报每天搜大量 AI 行业内容只写一期成品，这里是把其中的方法论和人物单独抽出来沉淀。

## 目录结构

- **`方法论/`** —— 72 篇独立文档，每篇含：来源 URL + 日报原文翻译（body）+（有精读稿的）细节 +「可以怎么用」。直接可拿去用或当博客素材。
- **`人物/作者名单.md`** —— AI 评测 / 模型质量 / 对齐测试相关人物名单，按相关度排序，含每人产出和链接。
- **`work/`** —— 中间产物：`scan/`（6 批逐期扫描原始记录，含所有被砍条目的存档）、`选题清单.md`（策展定稿，带强度标注和砍条目说明）、`prompts/`（派 subagent 用的提示词，复用时改这里）。

数据来源：`D:\dailydigest\reports\<日期>\daily.json`（成品）+ `work/digests/`（金银牌精读稿）。方法全部来自当天真实读到的材料，未联网补写。
