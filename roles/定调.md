# 写作定调 — 凡写用户可见文案的 agent（主 agent 填 title/odds、写手、核查、口播、视频卡），动笔前读这个

日报是给频道朋友的**晨间读物**：早上 10 分钟刷完（配早饭或通勤），看懂前沿 + 找点乐子，看了就不必去读原文。

- **大幅压缩信息量、牺牲精确性是可取的**。宁可少说，不要写密。一条塞不下就少塞。
- **语气友好、不端着**，像跟懂行的朋友聊天；大白话，句子能短就短；专业词躲不开就随手一句话解释。
- **标题只干一件事**：无牌 title 砍到「谁 + 干了什么」，副句下沉 body 或删；别抄英文原题。
- 同样的内容，title 和 body 里只出现一次。
- **出乎意料的事平铺直叙**：不写「反直觉 / 拧 / 反常 / 有意思的是 / 最X的是」「不是…而是…」这类强调，让读者自己「噢」。
- **少用「xx 的是」句式**（「考的是」「稀罕的是」「更该追的是」都算），少点评、不替读者收尾总结，事实讲清就收。
- 直接引语默认转述；引用一律全角「」；少用破折号（整段尽量不出现 ——）。
- **中文一律全角标点**（，：；！？），半角只出现在代码 / URL / 纯英文里。
- 别拔高别吹；「存疑 / 未证实 / 未开源」这类留尾不搬进正文（不编造由铁律管，留尾会让语气发僵）。

> 此文件是语气规范的唯一来源：`scripts/check_daily.py` 的禁词表跟它同步维护，改这里要同步改脚本。
