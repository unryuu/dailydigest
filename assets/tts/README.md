# 固定 TTS 片头

生产时直接使用 `固定片头.m4a`：

男声：「朋友们好。有温度、有态度。」

女声：「朋友们好。有温度、有态度，欢迎来到龙兄的 Daily Digest。」

两轨从开头同时播放；男声在「有态度」后的静音处结束。女声原始完整音轨从头连续播放到尾，不做裁切、拼接或淡化，再与截短的男声叠合。声音取自 08-13 的 `01.mp3` 原始分轨。`固定片头-初版.m4a` 是上一版片头备份。

分轨素材保留用于以后调整：

1. `片头-男声短句.m4a`：男声短句轨，后半段补静音。
2. `片头-女声完整句.m4a`：女声完整句轨。
3. `片头-叠音.m4a`、`片头-女声节目名.m4a`：上一版片头的分段素材。

当期语音从女声「今天是 X 月 Y 号」开始，后续按完整段落男女交替。

生成规则见 `steps/9-视频.md`。
