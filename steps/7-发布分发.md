# 步骤 7 · 发频道 + 口播稿 + 图文分发

## 发频道（铁律 1：仅在用户明说「发频道」之后）
`python scripts/send_daily.py <date> --to channel`，记消息 id。

## 口播稿（发频道后）
派 1 个写手 subagent（前台）：读 `roles/口播.md` + `reports/<date>/daily.json` + `work/digests/` + `inbox/<YYYYMMDD>/`（用户供稿目录，有就必读、最优先）。
产出 `reports/<date>/口播稿.md`。之后用户自己微调、录音，agent 不管录制。

## 图文分发（发频道后即可跑，不等录音；sandbox off）
```
python scripts/export_md.py <date>
python scripts/export_xhs.py <date>
python scripts/check_sensitive.py <date>
```
- 产出：`dist/daily.zhihu.md` + `dist/小红书/xhs-*.png`；公众号直接用 daily.full.png。
- 敏感词筛查命中（退出码 1）要处理完再发：删改措辞，或该条在国内平台版本剔除。
- **发布动作全部用户人工。**

## 拟标题（跟图文分发一起做）
**一个标题多平台共用**（知乎 / 小红书 / 公众号 / B 站），别各拟各的。
格式「爆点A，爆点B | M月D日AI日报」。**爆点只能用当期成品里写过的事实**，标题带的信息正文里要接得住。拟 2-3 个交用户定。
标杆是 07-23 那条跑出成绩的：`梁文锋罕见交底算力家底，闭源模型拒帮HF取证 | 7月23日AI日报`——两个爆点各是一个能让人「啊？」一下的具体事实，且主体不同。

等用户交来录音 → `steps/8-视频.md`；不做视频的日子直接 → `steps/9-收尾.md`
