# 步骤 8 · 视频线（等用户交来：微调过的口播稿 + 录音）

用户录音规矩：念错就拍下手、停一秒、从该句重念。录音放 `reports/<date>/video/`。
以下命令 sandbox off；转写约为音频时长 2.2 倍，**后台跑**；whisper 的 srt 路径不能带盘符冒号，所以 cd 进 `reports/<date>/video` 用相对路径。

1. **清理**：
   `ffmpeg -y -i reports/<date>/video/<录音> -af "highpass=f=110,highpass=f=110,adeclick,afftdn=nr=12:nf=-30" -c:a aac -b:a 160k reports/<date>/video/录音.clean.m4a`
2. **转写**：
   `cd reports/<date>/video && ffmpeg -y -i 录音.clean.m4a -af "aformat=sample_rates=16000:channel_layouts=mono,whisper=model=../../../models/ggml-large-v3-turbo-q5_0.bin:language=zh:destination=字幕.audio.srt:format=srt:queue=30:vad_model=../../../models/ggml-silero-v5.1.2.bin" -f null -`
3. **剪重念**：`python scripts/audio_retake.py reports/<date>/video/录音.clean.m4a reports/<date>/video/字幕.audio.srt reports/<date>/video/录音.final.m4a`（先无 `--apply` 出剪单）。
   ⚠️ **剪单必须对照转写逐段核、段数对上用户自报的拍手次数才动手**——排比句式和相邻同开头的短讯会误检，盲剪会伤正文。全对才 `--apply`；有误检就不 --apply，改用 ffmpeg 只剪真段：
   `ffmpeg -y -i 录音.clean.m4a -af "aselect='not(between(t,起,止)+between(t,起,止))',asetpts=N/SR/TB" -c:a aac -b:a 160k 录音.final.m4a`（区间抄剪单）。
   剪了就用剪后音频**重跑第 2 步**；没检出重念直接用 clean 版往下。
4. **对齐**：`python scripts/subs_align.py <date>` → 看匹配率；**停下，交用户手修 `video/字幕.script.srt` 的 ▲ 和错字；改完它是唯一源头，别再跑对齐覆盖**。
5. **抛光**：`python scripts/subs_polish.py reports/<date>/video/字幕.script.srt reports/<date>/video/字幕.script.final.srt 80`
6. **视频卡**：派 1 个 subagent 读 `roles/视频卡.md` + 口播稿（定稿）+ daily.json，起草 `reports/<date>/video/视频卡.json`，交用户改措辞。
   封面 `python scripts/video_cover.py <date> "<M 月 D 日>" "<金银看点 · 分隔一行>"`；
   定时 `python scripts/video_cards.py <date>`（核：anchor 全锚上、时间单调）。节目名「龙兄的 Daily Digest」脚本自带。
7. **烧录**：
   `cd reports/<date>/video && ffmpeg -y -f concat -safe 0 -i cards.ffconcat -i 录音.final.m4a -vf "fps=25,subtitles=字幕.script.final.srt:force_style='FontName=Microsoft YaHei,FontSize=24,PrimaryColour=&H00272E2F,OutlineColour=&H00FFFFFF,Outline=2,Shadow=0,BorderStyle=1,MarginV=34'" -c:v libx264 -preset veryfast -crf 23 -pix_fmt yuv420p -c:a aac -b:a 128k -shortest 视频.稿件字幕.mp4`（没剪重念就把音频换成 录音.clean.m4a）

验收：读回成片时长、抽一两帧看卡片和字幕。**B 站标题拟双核心格式「爆点A，爆点B | M月D日AI日报」交用户定**，发布人工。
视频产物（srt ×3、视频卡.json、视频卡/、封面、cards.ffconcat）补一次 commit。下一步 → `steps/9-收尾.md`
