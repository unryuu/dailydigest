# 步骤 8 · 视频线（等用户交来：微调过的口播稿 + 录音）

用户录音规矩：念错就拍下手、停一秒、从该句重念。录音放 `reports/<date>/video/`。
以下命令 sandbox off；转写**后台跑**（macOS(M2) 实测约为音频时长的 0.1 倍，8 分钟录音 50 秒出头）；ffmpeg 滤镜里路径不能带冒号（冒号是选项分隔符），所以 cd 进 `reports/<date>/video` 用相对路径。

1. **清理**：
   `ffmpeg -y -i reports/<date>/video/<录音> -af "highpass=f=110,highpass=f=110,adeclick,afftdn=nr=12:nf=-30" -c:a aac -b:a 160k reports/<date>/video/录音.clean.m4a`
2. **转写**（`whisper-cli`，先转 16k 单声道再转写；产出 `字幕.audio.srt`）：
   `cd reports/<date>/video && ffmpeg -y -i 录音.clean.m4a -ar 16000 -ac 1 -c:a pcm_s16le 录音.clean.16k.wav`
   `cd reports/<date>/video && whisper-cli -m ../../../models/ggml-large-v3-turbo-q5_0.bin -l zh -f 录音.clean.16k.wav --vad -vm ../../../models/ggml-silero-v5.1.2.bin -ml 12 -osrt -of 字幕.audio`
   ⚠️ **`-ml 12` 不能省**。不加的话 whisper-cli 切段是 60 段 / 平均 7.25s / 39 字，而往期九期是 177~274 段 / 2.7~3.0s / 11 字左右。段越长，`subs_align` 的段内字符线性插值越粗、字幕时间点越飘。加上后回到 225 段 / 10.4 字，落进往期区间（07-30 实测）。
   > 原先这步用 ffmpeg 的 whisper 滤镜。macOS(M2) 上那条路跑不上 GPU——484 秒音频要约 3.1 小时（CPU 时间 1066 秒、7 核满载），whisper-cli 走 Metal 只要 50.7 秒，转写文字一致。Windows 上滤镜是 2.2 倍实时、正常，但两边统一走 cli 更省心。滤镜命令留在 git 历史里（07-30 之前的版本）。
3. **剪重念**：`uv run scripts/audio_retake.py reports/<date>/video/录音.clean.m4a reports/<date>/video/字幕.audio.srt reports/<date>/video/录音.final.m4a`（先无 `--apply` 出剪单）。
   ⚠️ **剪单必须对照转写逐段核、段数对上用户自报的拍手次数才动手**——排比句式和相邻同开头的短讯会误检，盲剪会伤正文。全对才 `--apply`；有误检就不 --apply，改用 ffmpeg 只剪真段：
   `ffmpeg -y -i 录音.clean.m4a -af "aselect='not(between(t,起,止)+between(t,起,止))',asetpts=N/SR/TB" -c:a aac -b:a 160k 录音.final.m4a`（区间抄剪单）。
   剪了就用剪后音频**重跑第 2 步**；没检出重念直接用 clean 版往下。
4. **对齐**：`uv run scripts/subs_align.py <date>` → 看匹配率；**停下，交用户手修 `video/字幕.script.srt` 的 ▲ 和错字；改完它是唯一源头，别再跑对齐覆盖**。
   - **字幕只放念出来的话**。勘误、补充、注释一律不进字幕——字幕跟着音频走，加了字观众会觉得话没说完就切走了。这类内容留给发布时的简介（07-25 实跑教训）。
   - ▲ 是「一条字幕跨了两个段落」，不是错字。不想切就把中间的句号改成分号，抛光只删行尾标点、行中的留得住。
   - 字幕单行容量约 50 个全角宽度，超了折两行。**4 条 bullet 和两行字幕兼容**——轻微接触，不影响观看，**别当故障报**；**5 条才会真重叠**。真要治重叠就从源头压字数或减 bullet，**别靠调小 `MarginV`**——字幕贴底会被视频网站的进度条挡掉（07-25 用户指出）。
5. **抛光**：`uv run scripts/subs_polish.py reports/<date>/video/字幕.script.srt reports/<date>/video/字幕.script.final.srt 80`
6. **视频卡**：派 1 个 subagent 读 `roles/视频卡.md` + 口播稿（定稿）+ daily.json，起草 `reports/<date>/video/视频卡.json`，交用户改措辞。
   封面 `uv run scripts/video_cover.py <date> "<M 月 D 日>" "<金银看点 · 分隔一行>"`；
   定时 `uv run scripts/video_cards.py <date>`（核：anchor 全锚上、时间单调）。节目名「龙兄的 Daily Digest」脚本自带。
7. **烧录**——**先量后烧两步，禁用 `-shortest`**：
   - 量音频时长：`ffprobe -v error -show_entries format=duration -of default=noprint_wrappers=1:nokey=1 reports/<date>/video/录音.final.m4a`
   - 把量到的秒数填进 `-t`：
   `cd reports/<date>/video && ffmpeg -y -f concat -safe 0 -i cards.ffconcat -i 录音.final.m4a -vf "fps=25,subtitles=字幕.script.final.srt:fontsdir=../../../fonts:force_style='FontName=Microsoft YaHei,FontSize=24,PrimaryColour=&H00272E2F,OutlineColour=&H00FFFFFF,Outline=2,Shadow=0,BorderStyle=1,MarginV=34'" -c:v libx264 -preset veryfast -crf 23 -pix_fmt yuv420p -c:a aac -b:a 128k -t <音频时长> 视频.稿件字幕.mp4`（没剪重念就把音频换成 录音.clean.m4a，时长也量那一个）
   ⚠️ **别图省事用 `-shortest`**：图卡 concat 场景下它不按音频收工，片尾会留静音冻帧。07-25 同素材对照实测——音频 738.450s，`-t` 出 738.450s，`-shortest` 出 744.560s（多 6.11s）；07-24 那次多 9.6s。**多出的秒数每期不同**，别当固定值。反过来，`-t` 填错会切短片尾，所以务必先量再烧、烧完读回时长核对。

验收：读回成片时长、抽一两帧看卡片和字幕。**B 站标题用步骤 7 已定的那个**（多平台共用，别另拟），发布人工。
视频产物（srt ×3、视频卡.json、视频卡/、封面、cards.ffconcat）补一次 commit。下一步 → `steps/9-收尾.md`
