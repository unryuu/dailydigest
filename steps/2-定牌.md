# 步骤 2 · 定牌（主 agent 自己做）

## 先读三样
1. `reports/<date>/work/manifest.json`
2. **昨天的 `reports/<昨日>/daily.json` 全文**——这是防内容重复的主防线。URL 查重只能拦同链接；昨天正文里写过的观点、引语、事件侧面，今天换个链接再出现一样算重复（例：昨天银牌末句引过某人的话，今天就不能拿他这句话单独成条）。
3. `uv run scripts/recent_titles.py <date>` 的输出（近 3 期标题清单）——兜前两期的标题级重复；同一事件的后续转评、二手复述都算旧闻，除非有实质新事实。

## 定牌
- 候选归进八个内容分区：**行业大事 / 独家视角 / 深度长文 / 新鲜论文 / 监管动向 / 官方公告 / 行业简讯 / 乐子汇总**（方法论文章进论文或长文都行），赔率先记着步骤 5 用。
- 每区内部定档：**金**（两段 ≤250 字）/ **银**（一段 ≤150 字）/ **无牌**（≤2 句 65 字）。
- **独家视角**（2026-07-27 加）：几条话题靠近的内容，并成一段来聊比分开摆更有意思时用，≤350 字，不挂金银。**不是每期都有**，凑不出就别硬凑。用掉的料从原分区移走，别两处都出现。
- **行业简讯**（2026-07-27 加）：连无牌都不够格、但丢了可惜的，收进来一句话带过，只有标题、≤30 字、没有 body。它会从各区（尤其乐子）吸走条目，定牌时注意别把某个区抽空。
- **金银只给 AI 行业内**；乐子放宽到理性主义/非 AI/有梗。讣闻不进乐子区（挪行业大事或合适的区）。
- 某类平淡不强选金银；某类没内容当天整区去掉。每类 3-5 条、监管公告通常更少——日报是早晨十分钟的读物，分量别跟着料涨。

## 密度红线
- **同一主线单日最多 1 条**；确属当日金牌级事件，可金牌 + 1 条周边，封顶 2。饱和主线（STATUS 列的）只收真新进展，进展只值一句就并进已有条目，不单独成条。

## 交出去之前
定牌清单**跟用户过一遍**（他常复核、挑、降档）。

展示格式：**分区用二级标题，每区一张 markdown 表格**（列＝档位 / 标题 / 备注），比纯文字列表好扫。备注列写清重复风险、低信度、密度红线这些要他裁决的点。表格后另起一节列**你砍掉的候选和理由**，让他能捞回来。

产出：定牌清单（各区金银无牌 + 赔率候选）。下一步 → `steps/3-精读.md`
