# 步骤 6 · 自查 + 渲染 + 预览

## 自查（两条命令）
```
uv run scripts/check_daily.py <date>
uv run scripts/check_dup_urls.py <date>
```
- check_daily 一次查完：结构（分区/tier/url）、三硬坑（`<br>`、裸引号、裸 `<>&`）、禁词（与 roles/定调.md 同步维护）、半角标点（load 时已自动归一化，报的是修正数）、字数警戒线。**error 必须清零；warning 逐条人工过，不是必须清零。**
- check_dup_urls 这次查的是 daily.json，兜底防止定牌后又混进往期 URL。

## 渲染 + 预览（联网开 sandbox off）
1. `uv run scripts/render_daily.py <date>` → **读回 daily.full.png 尺寸核实**。
2. 首次预览前快照：`[ -f reports/<date>/work/daily.preedit.json ] || cp reports/<date>/daily.json reports/<date>/work/daily.preedit.json`（存写手+赔率的预览版，收尾对照用户修改用；重渲不覆盖）。
3. `uv run scripts/send_daily.py <date>`（默认发私聊）。记消息 id。

## 用户改稿循环
用户直接编辑 daily.json（尾逗号、半角标点脚本自动容错回写，不用手修）。他说改完 → 重跑 check_daily → 重渲 → 重发预览。

产出：daily.full.png + work/daily.preedit.json + 私聊预览已发。下一步 → `steps/7-发布分发.md`
