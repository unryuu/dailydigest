# 步骤 9 · 收尾（做完即止，不做第二期）

1. **seen 回写**：`uv run scripts/update_seen.py <date>`——按域名自动匹配源、前插 `{id,title,date,reported,report_date}`（幂等）。脚本报「未匹配」的条目手动补进对应源的 seen.json。
2. **整理用户修改**：对照 `work/daily.preedit.json` 与最终 `daily.json`，把「前→后」逐条 + 一节「归纳（修改模式 → 规范候选）」写进 `reports/<date>/用户修改.md`。用户没改就一句「本期无改动」。
3. **写 `reports/<date>/report.md`** 存档：定牌表、reader 纠偏、赔率取舍、写作复盘、**当期事故与教训全写这里**（STATUS 只留一行）。
4. **更 `STATUS.md`**（格式别改，只改内容）：
   - 顶部「最近一期 / 下一期」改日期；观察点有变就更。
   - 「防重复」节滚动：主线加新去旧（超过 3 期没动静的线删掉）、赔率清单加当期去最老一期。
   - 「最近 3 期」加当期一行、删最老一行（删掉的不用留档，report.md 里都有）。
5. **commit + push**：`git add reports/<date> sources STATUS.md` → commit（中文一句话概括当期）→ push。commit 前 `git ls-files config.local.json` 应为空。

完事即止，交接给下一个窗口。
