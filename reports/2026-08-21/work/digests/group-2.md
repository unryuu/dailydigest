# AT&T 用模型路由把轻任务交给开放模型

- 推荐强度: 强
- 档位线索: 够银。它不是一次模型跑分，而是大型企业每天约 450 亿 token 的真实多模型部署：用路由按任务难度分工，部分任务以约 2％的内部质量降幅换来最高 56％的成本下降。金牌仍偏勉强，因为所有效果数字均为公司内部口径，缺少任务集、评分方法与独立审计。
- 涉及文章: [AT&T is Using Open Source Models to Curb Anthropic Bills](https://www.theinformation.com/newsletters/applied-ai/t-using-open-source-models-curb-anthropic-bills) · The Information · 2026-08-20

## 核心主张
AT&T 没有在开放模型与前沿闭源模型之间二选一，而是让路由器按任务难度分配模型：复杂代码生成仍交给 Anthropic、OpenAI 等前沿模型，代码摘要等较轻任务则转给 Nemotron、Llama 和 Gemma。公司称，这种分工让部分编码等高级任务的成本最多下降 56％，内部测得的质量约下降 2％；计划未来几年继续提高开放模型承接的查询比例，同时让 Anthropic 与 OpenAI 的模型支出基本不变。

## 为什么值得看（钩子）
开放模型真正进入企业，不一定靠全面替代最强闭源模型，而可能先吃掉大量不需要最强能力的日常请求。AT&T 的规模让这个路由策略不再只是小型评测或产品宣传，而是一个可观察的企业部署样本。

## 关键细节 / 引述
- AT&T 目前约 40％的员工 AI 查询由开源或开放权重模型处理，计划未来几年提高到 60％至 70％。
- 内部系统每天处理约 450 亿 token。
- 复杂代码生成仍留给前沿闭源模型；代码摘要等较轻任务交给 Nemotron、Llama 和 Gemma。
- AT&T 使用 LiteLLM 做模型路由后，部分编码等高级任务的成本最多下降 56％，内部测得的质量下降约 2％。
- 公司称开放模型通常落后前沿模型六至十个月，但差距正在缩小；DeepSeek 和 Moonshot 模型仍在风险评估中，尚未投入工作使用。
- 查询比例、成本与质量变化均来自 AT&T 负责人的内部口径，报道未提供任务集、评分方法或独立审计。公开价格只能用于外部估算，不能写成 AT&T 已披露的实际账单。本地抓取页为订阅墙短壳，以上事实以主 agent 的登录态精读记录为准。
