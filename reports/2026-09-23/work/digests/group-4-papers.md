# 多 Agent 与研究 Agent

- 推荐强度：中
- 档位线索：Agensh、AIDE² 给银牌；Taste-Bench、RoboFollow 无牌。
- 涉及文章：[Agensh](https://arxiv.org/abs/2609.26781) · 09-22；[AIDE²](https://arxiv.org/abs/2609.26457) · 09-22；[Taste-Bench](https://arxiv.org/abs/2609.25804) · 09-22；[RoboFollow](https://arxiv.org/abs/2609.25636) · 09-22。

## 核心主张
Agensh 让工作 Agent 在共享空间里自己认领任务、交流和验收，省去单一总指挥的协调瓶颈。AIDE² 在八天内反复修改自己的研究 Agent 代码并用留出的任务筛选，累积七轮改进。Taste-Bench 测任务过程中的判断力；RoboFollow 发现具身 Agent 有时靠画面猜任务，语言指令变了就出问题。

## 关键细节
- Agensh 在五项软件任务里从1扩到128个Agent，平均最终测试通过率由19.31％升至28.78％；一项pandoc任务扩到1024个时由33.89％升至55.06％。不同任务不要混成统一成功率。
- AIDE² 的自改动涉及搜索策略和管理长上下文的记忆机制；四项未参与筛选的基准涵盖机器学习工程、启发式算法和天气预测，最强版本达到或超过论文中的人类设计研究 Agent。这里改的是 Agent 程序，不是模型权重。
- Taste-Bench 让模型只看到长任务的分岔点、选后续路线，最好模型答对59.7％；更长推理没有提高判断准确率。
- RoboFollow 让同一场景可以执行多种动作，再用不同指令测试机器人是否分得清。九套策略在简单设置取得的好成绩，未能稳定迁移到改变指令或场景的设置。
