# GPT-6 Sol／Luna 与 Claude Opus 5.5

- 推荐强度：强
- 档位线索：用户已认可两个金牌；两条各讲一家公司，避免同一段罗列跑分。
- 涉及文章：[OpenAI 官方](https://openai.com/index/introducing-gpt-6-sol-and-luna/) · 09-22；[Anthropic 官方](https://www.anthropic.com/claude-opus-5-5) · 09-22；[Simon 实测](https://simonwillison.net/2026/Sep/22/opus-and-sol-and-luna/) · 09-22。

## 核心主张
OpenAI 把 Astra 的部分方法带到更快、更便宜的 Sol 与 Luna，用来扩展日常任务和开发者工作。Anthropic 的 Opus 5.5 在编程与知识工作上向 Fable 5.1 靠近，同时降低长任务成本，改善沟通风格。两家同一天把中档强模型价格压低，读者关心的是任务结果、费用和实际体验。

## 关键细节
- Sol API 输入／输出每百万 token 2／10 美元，Luna 为0.10／0.50美元；相对各自5.6促销价格下降约一半。Sol 和 Luna 已用于 ChatGPT Work、Codex 和 API，ChatGPT 逐步开放。
- OpenAI 内部事实性测试中，Sol 在特意挑出的历史错误对话上，错误量约为前代一半；该测试不是日常使用错误率。
- Anthropic 称 Opus 5.5 典型任务的运行成本比 Opus 5 低40％；API 常规输入／输出每百万 token 4／20美元，比前代低20％；缓存读取低60％；输出速度快30％以上。
- Anthropic 公布编程、知识工作和自动行为审计的新成绩，沟通表述是改进重点。实验室称它在多项工作接近 Fable 5.1。
- Simon 自己试了 Opus 5.5 max 思考档两次画 SVG 骑车鹈鹕，都在输出耗尽前没给最终结果，各耗时近20分钟、2.56美元；这只说明一个极端档位在他的任务里失败，可独立成乐子。

## 与近期的关系
Astra 已于此前发布，本次增量是 Sol／Luna 与 Opus 5.5 的能力和价格。近几期已报模型发布常降级，但用户在本期明确点名重磅、定牌直接推进。
