# 有人把自己接进 Codex 的 Agent Loop

- 来源：[Tentacle Monster Roleplay ESP32](https://github.com/ra1nyxin/tentacle-monster-roleplay-esp32) · GitHub · 2026-08-27 当轮核实
- 用途：口播稿乐子条展开素材。日报正文只写一行，口播可稍微详细讲清循环。

## 核实事实

- 这是一个本地角色扮演互动工具，把 iPhone 摄像头、Codex 剧本主持和 ESP32-S3 反馈设备接在一起。
- iPhone Safari 会持续把画面上传到 Windows 电脑，最新一帧保存为 `latest.jpg`。Codex 读取画面，把玩家的姿态、服装、道具和动作解释成 RPG 场景。
- Codex 扮演触手小怪物，按画面推进剧情。需要反馈时，它可通过本地桥向 ESP32-S3 设备发送强度、单次触发和停止等命令。
- 这个玩法特意设计成非回合制：反馈设备在后台运行时，Codex 立刻继续读取新画面，观察玩家反应，再调整剧情目标、强度和节奏。
- 仓库要求所有自动反馈都有明确的强度与时间上限，并提醒不要提交摄像头画面、日志和本地证书等私人文件。
- README 记录的实测组合为 OpenAI Codex、GPT-5.5、Windows 本地桥、iPhone Safari 和 ESP32-S3 串口桥。
