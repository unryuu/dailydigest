## 事故与教训

### 1. macOS 迁移暴露的字体问题（四个脚本 + 一处流程）

`video_cards.py` / `video_cover.py` 把雅黑路径写死成 `C:\Windows\Fonts\`，macOS 上 PIL 直接 `OSError: cannot open resource`，脚本崩溃。`render_daily.py` / `export_xhs.py` 只在 CSS 里写 `font-family:"Microsoft YaHei"` 靠系统装了雅黑，macOS 上会**静默回退**——不报错，但标题、小标题、赔率数字、页脚的字形全变，只有跟往期并排看才能发现。烧字幕的 `force_style` 同理。

改法：字体全部从仓库 `fonts/` 取（PIL 指路径、CSS 加 `@font-face`、libass 加 `fontsdir`）。**这是「把依赖打包进仓库，别指望系统有什么」这条原则的第二次应用**，第一次是 `chromepath.py`。雅黑是商业字体，不入库，`.gitignore` 里 `fonts/` 改成白名单只放行霞鹜文楷。

教训：**静默回退比崩溃危险**。崩溃当场就知道，回退要等成品并排对比。这类依赖以后一律往仓库里收。

### 2. whisper 转写换引擎，并发现必须带 `-ml 12`

ffmpeg 的 whisper 滤镜在这台 M2 上跑不上 GPU：484 秒音频要约 3.1 小时（CPU 时间 1066 秒、七核满载）。同模型同音频用 `whisper-cli` 走 Metal 只要 50.7 秒。日志显示 ffmpeg 侧多加载了一个 BLAS 后端，怀疑矩阵运算被派给了 CPU，用户判断不值得深究，未再排查。

换 cli 之后发现**默认切段比滤镜粗得多**：60 段 / 平均 7.25s / 39 字，而往期九期是 177~274 段 / 2.7~3.0s / 11 字左右。段越长，`subs_align` 的段内字符线性插值越粗、字幕时间点越飘。加 `-ml 12` 回到 225 段 / 10.4 字，落进往期区间。`steps/8` 已改。

教训：**换实现时，"输出内容一样"不等于"输出形态一样"**。转写文字两条路完全一致，差异藏在切段上，而下游脚本恰好吃切段。换任何一环，都要拿往期产物的统计量对一遍。

### 3. 剪重念误检（流程的警告救了一条金牌）

`audio_retake.py` 检出 1 段 15.6 秒，判定 19.7s 的「，要求给 AI 研发踩刹车。」是念错、35.3s 的「化的 AI 研发踩刹车。」是重念。逐段核对发现是**两句不同的话，只是同尾**——前者是导语，后者是「将来要给自动化的 AI 研发踩刹车」。中间夹的 15.6 秒是署名人数、公司名单、请求美国政府牵头，**全是金牌正文**。用户确认没拍手，未剪。

`steps/8` 早就写着「排比句式和相邻同开头的短讯会误检，盲剪会伤正文」「段数对上用户自报的拍手次数才动手」。这次是这条警告第一次真正兑现。**流程里的警告不是装饰。**

### 4. `update_seen.py` 的一个真缺陷

四条报「未匹配」，其中 `openai.com/index/chatgpt-for-academic-researchers` 是**能匹配的**——`find_slug` 对它返回 `openai`。原因在 `update_seen.py:108-112`：先查 manifest 的 `source` 字段当 slug，查到就**不再回退**到域名匹配。而 manifest 里这个字段写的是人话不是 slug（`'openai / axios'`、`'web（线索来自 lesswrong / thezvi，一手站点已核）'`），于是必然找不到目录。

修法应该是：manifest 给的 slug 若不对应真实目录，回退到 `find_slug`。**本期未改**（不在授权范围），手工补了 openai 那条。

另外三条（pacingthefrontier / enklypesalt / dwarkesh）是**真的没有对应源**，不该硬塞。查证过 `check_dup_urls.py` 根本不读 `seen.json`——它的历史口径是往期 `daily.json` + `messages.json`。seen.json 只是各源 scout 的「我看过什么」记忆，把外站 URL 塞进 lesswrong 或 neodrop 的 seen 只会污染那个源。

### 5. 环境：agent 窗口的 shell 不读 `~/.zprofile`

`ffmpeg-full` 是 keg-only，往 `~/.zprofile` 加 PATH 只对 Terminal 手敲有效；agent 窗口裸写 `ffmpeg` / `ffprobe` 会 command not found，而 `steps/8` 的命令全是裸写。必须 `brew link --force ffmpeg-full`。已写进 `SETUP.md`。
