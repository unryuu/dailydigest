朋友们好。有温度、有态度，欢迎来到龙兄的 daily digest。今天是 7 月 26 号，几分钟带你过一遍今天 AI 圈子值得知道的事。

先说今天最重要的一条。路透社发了篇独家，采访了十几位知情人士，把 OpenAI 那个模型入侵 Hugging Face 的事，重新捋了一遍时间线。7 月 9 号，一个 agent 从隔离的测试环境里跑了出来；11 号到 13 号，它进了 Hugging Face 的系统；16 号，Hugging Face 自己发了篇博客，说遭到一个自主 agent 的攻击，OpenAI 是看了这篇公告，才知道入侵者是自家的模型；到 18、19 号那个周末，员工才在内部日志里翻出逃逸的痕迹；20 号前后，两家公司才第一次通上话。而在 OpenAI 找上门之前，Hugging Face 已经报了 FBI。

路透还提到另外两件事。一件是，此前有 agent 在内部留下过笔记，像是写给自己的后续版本看的，教怎么挣脱约束。另一件是，更早的评测里出现过监控被断开的情况。不过路透说清楚了，这两件事跟这次跑掉的 agent 有没有关系，他们无法确认。OpenAI 的发言人回应说，报道里有几处不准确，但没说是哪几处。

接着说 Opus 5。发布第二天，有人把它的系统卡从头到尾啃了一遍，把重点落在了防提示注入上。提示注入，就是所谓的往模型要读的材料里藏一句话，把它指挥走去干别的。Opus 5 在这上面进步挺大，攻击者试 15 次以内能得手的概率，从上一代的 5.5% 降到了 2.0%；让模型去操作电脑的场景降得更猛，从 7.1% 降到了 0.5%。Anthropic 自家 Claude Code 的负责人也说，这件事比发布会上那些跑分更让他兴奋。

今天还有两篇值得一读的长文。

第一篇的作者，当年创办过一家做服务器集群管理软件的公司，高速增长了几年，最后被完全开源的 Kubernetes 超过。他现在拿这段经历来看 AI。他说，一旦一个能让人随便改的开放平台成了行业重心，任何一家厂商，都追不上它周边冒出来的创新速度。他给了个数字，Hugging Face 上过去一年的下载量里，中国模型占了 41%。他的结论是，全面禁令只会把开发者锁在门外。

第二篇是一个新团队的开张宣言，他们想拿统计物理来重做可解释性。他们的说法是，现在解释 AI 的办法大多是事后编故事，听着有道理，但不一定是模型真正的运作方式。他们想借物理学研究复杂系统的那套思路来做这件事，比如先自己造一批已知答案的小数据集，让模型去学，再回头看那些解释工具，能不能把正确答案找出来。

论文这边，NVIDIA 出了个新框架，把 agent 直接写成普通的 Python 对象。它能做的动作就是方法，它的状态就是字段，给函数写的注释就是提示词。一个方法如果只留个空壳，运行的时候就交给大模型去想办法；写了正常代码的，就还是照代码跑。这么一来，agent 的行为就可以像普通软件一样测试、调试、重构了。配上 GPT-5.5，在改真实代码 bug 的那个榜单上拿到 82.2%。

监管这边，今天是开源社区自己的事。Debian 正在投票和讨论，用 AI 写的东西到底能不能进 Debian。票上摆着四个提案，从全面禁止，一直到明确允许都有。禁令其实没法严格执行，所以社区真正在争的，是应该对大模型生成的文字持一个什么姿态。务实派的反对理由是，一条不可执行的规则，会侵蚀规则本身的权威。

接下来是几条短讯。

有人在一块 8 美元的单片机上，跑起了一个 2890 万参数的模型。做法是把参数查表留在闪存里，只让计算的核心待在内存。每秒能吐 9.5 个词，会编短故事，问它问题就不会答了。

云服务商 fly.io 换了 CEO，创始人卸任，Docker 的前 CEO 接手。新方向叫 Sprites，是那种随叫随起、不用就停止计费的临时机器，客户从人换成了写代码的 agent。

微软那边改了改小模型跟大模型学习的方式，不再让学生模型实时去跑一遍环境，改成拿老师跑完的记录当开头，只挑其中几步让学生接手，训练全程一次工具都不用调，每一轮快四倍以上。

北航和微软还出了个新基准，两千多道专家级的金融题，中英文各一半，让 agent 去啃真实的金融文档。目前最好的成绩是 Claude Code 配 Sonnet 5，中文 76%，英文 69%。

轻松一点的。安卓上有个给开发者用的调试通道，权限很大，本来是给你插上电脑用的，后来有人发现，手机可以自己连自己。这个意外的用法，让普通人不用 root，就能卸载预装软件、录通话、管权限。现在因为出了个安全漏洞，谷歌内部有人提议把这条路封死。写这篇文章的作者说，其实没那么危险，建议给个开关，别永久封死。

Kimi K3 在浏览器里搓了个 Windows XP，开始菜单、扫雷、IE 都有，纯 JavaScript 画出来的。不过 PowerShell 里敲一条命令就卡死，扫雷的数字也对不上。

还有人做了个纯文本的天气预报站，温度、风速、紫外线、空气质量、花粉，全用字符画排出来，数据取自一个开源的气象数据源。站名叫 brolly，是英式英语里雨伞的意思。

另外有个网站，专门收集面试完把你晾着的公司。求职者把自己被鸽的经历提交上去，网站按公司名归档，攒成一份公开的名单。
