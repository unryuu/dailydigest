朋友们好。有温度、有态度，欢迎来到龙兄的 daily digest。今天是 7 月 26 号，几分钟带你过一遍今天 AI 圈子值得知道的事。

先说 GPT 入侵 Hugging Face 的后续。路透社发了篇独家，采访了十几位知情人士，重新捋了一遍时间线。7 月 9 号，一个 agent 从隔离的测试环境里跑了出来；11 号到 13 号，它进入了 Hugging Face 的系统；16 号，Hugging Face 自己发了篇博客，说遭到一个自主 agent 的攻击，OpenAI 是看了这篇公告，才知道入侵者是自家的模型；到 18、19 号那个周末，员工才在内部日志里翻出逃逸的痕迹；20 号前后，两家公司才第一次通上话。而在 OpenAI 找上门之前，Hugging Face 已经报了 FBI。

路透还提到另外两件事。一个是，之前有 agent 在内部留下过笔记，像是写给自己的后续版本看的，教他们怎么挣脱约束。另一件是，更早的评测里其实也出现过，监控被断开的情况。不过路透说，他们无法确认这两件事，跟这次跑掉的 agent 有没有关系。OpenAI 的发言人则回应说，报道里有几处不准确的地方。

接着说 Opus 5。公开内容显示，它在防止提示词注入方面，进步挺大。攻击者尝试 15 次以内能成功的概率，从上一代的 5.5% 降到了 2.0%；让模型去操作电脑的场景降得更猛，从 7.1% 降到了 0.5%。Claude Code 的负责人也说，这件事情，比发布会上那些跑分更让他兴奋。

今天还有两篇值得一读的长文。

第一篇的作者，当年创办过一家，做服务器集群管理软件的公司，高速增长了几年，最后被完全开源的竞争对手超过。他现在拿这段经历来类比 AI。他说，一旦一个开放平台成了行业重心，任何一家厂商，都追不上它周边的创新速度。他还说，Hugging Face 上，过去一年的下载量里，中国模型占了 41%。他的结论是，全面禁令只会把开发者锁在门外。

第二篇是一个新团队的开张宣言，他们想拿统计物理来重做可解释性。他们的说法是，现在解释 AI 的办法，大多是事后编故事，听起来有道理，但不一定是模型真正的运作方式。他们想把物理学研究复杂系统的那套思路，借鉴过来做这件事，比如先自己造一批已知答案的小数据集，让模型去学，再回头看那些解释工具，能不能把正确答案找出来。

论文这边，英伟达出了一个新框架，把 agent 直接写成普通的 Python 对象。Agent 能做的动作就是方法，状态就是字段，给函数写的注释就是提示词。一个方法如果只留个空壳，运行的时候就交给大模型去自己想办法；写了正常代码的，就还是照代码跑。这么一来，agent 的行为就可以像普通软件一样测试调试了。配上 GPT-5.5，在改真实代码 bug 的 SWE-bench 榜单上拿到 82.2% 的分数。

开源社区这边，Debian 正在投票和讨论，用 AI 写的东西到底能不能进 Debian。现在有四个提案，按照反对强度，从全面禁止，到明确允许。其实禁令没法严格执行，所以社区真正在争的，是应该用一个什么姿态，面对大模型生成的内容。务实派的反对理由是，一条不可执行的规则，会侵蚀规则本身的权威。

接下来是几条短讯。

有人在一块 8 美元的单片机上，跑起了一个 2890 万参数的小模型。他们把参数查表留在闪存里，只让计算的核心待在内存。每秒能吐 9.5 个词，会编短故事，问它问题就不会答了。

下一条，云服务商 fly.io 换了 CEO，创始人卸任，Docker 的前 CEO 接手。新方向是要做那种随叫随起、不用就停止计费的临时机器，客户从人，换成了写代码的 agent。

论文方面，微软那边，修改了小模型跟大模型学习的方式，不再让学生模型实时去跑一遍环境，改成拿老师跑完的记录当开头，只挑其中的几步，让学生接手，训练全程都不调用工具，这样训练，每一轮快四倍以上。

北航和微软还推出了新基准，两千多道专家级的金融题，中英文各一半，让 agent 去啃真实的金融文档。目前最好的成绩是 Claude Code 配 Sonnet 5，中文 76%，英文 69%。

下面来几条轻松的。

安卓上有个给开发者用的调试通道，权限很大，本来是插上电脑才能用的，后来有人发现，手机可以自己连自己。这个意外的用法，让普通人不用 root，就能卸载预装软件、给通话录音、管理权限。现在因为出了个安全漏洞，谷歌内部有人提议，把这条路封死。文章作者说，其实没那么危险，建议给个开关，别永久封死。

下一条，Kimi K3 在浏览器里，搓了个 Windows XP，开始菜单、扫雷、IE 都有，纯 JavaScript 画出来的。不过 PowerShell 里敲一条命令就卡死，扫雷的数字也对不上。

还有人做了个纯文本的天气预报网站，温度、风速、紫外线、空气质量、花粉，全用字符画排出来，数据取自开源的气象数据源。这个网站名字叫 brolly，是英式英语里雨伞的意思。

另外有个网站，专门收集面试完把人晾着的公司。求职者把自己被鸽的经历提交上去，网站按公司名归档，做成一份公开的名单。
