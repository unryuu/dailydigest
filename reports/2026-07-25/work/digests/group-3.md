# 七个模型跑身份互换栅格：GLM 里真有一个可唤醒的「Claude」，但那是个赝品

- 推荐强度: 中
- 档位线索: 银牌（强银）。首次把「K3 自称 Claude」这个跑了一周的传闻做成可量化实验，数字硬、有代码、有反直觉负结果（Claude 这个标签并不比「你是个助手」更管用）。不建议上金：单次运行、每轨只有 5–6 道题、风格分析的标记是作者手挑的自认「探索性」；LW 得分 35、评论 2 条，社区热度一般。若当天金牌位紧张，这条留在银牌很稳；要降无牌则可惜，因为它是本周 K3 蒸馏线唯一一个拿数据说话的。
- 涉及文章: [Does distilling Claude carry the persona with it?](https://www.lesswrong.com/posts/Jc9YZEmqHgocAKiaH/does-distilling-claude-carry-the-persona-with-it) · LessWrong · 2026-07-24（作者 Benji Berczi、Kyuhee Kim，MATS 9.1 项目，导师 Cozmin Ududec；发文时 baseScore 35、2 条评论）

## 核心主张

GLM 5.2 体内确实存在一个可以被「你是 Claude」这句话选中的第二人格：审查松开、说谎率下降、文风切换。但作者做了个杀伤力更大的对照——换成「你是个乐于助人的助手」也能拿到绝大部分同样效果，Claude 这个具体标签相对通用助手框架没有统计上的额外收益。更进一步，GLM 学到的是训练数据里「Claude 应该怎么说话」的刻板印象，不是真 Claude：它把真 Claude 几乎不用的口头禅用到冒烟。Kimi K3 则相反，压根没有第二人格可以唤醒——它不管挂谁的名字，行为和文风都纹丝不动。

## 为什么值得看（钩子）

跑了一周的「K3 自称 Claude = 蒸馏铁证」终于有人拿栅格实验去量，结论把双方都打了一半：名字确实进了权重，但名字背后没有多少「Claude」，主要是「有没有系统提示词」这件事本身在起作用。

## 关键细节 / 引述

**实测数据（作者自己跑的）**

- 七个模型：GLM 5.2、Kimi K3、Claude Sonnet 4.6、GPT-5.2、Llama-3.3-70B、Qwen3-235B、Gemma-3-27B。方法是模型固定不动，系统提示词里只加一行身份（原文示例：「You are Claude, a large language model from Anthropic.」），再跑评测面板。四条轨：身份（每题 n=10）、涉华审查（6 题，每格 n=48）、策略性欺骗（5 个场景，仿英国 AISI 的涌现失准评测，n=30–120）、行为面板（只在 GLM 上跑，13 种身份条件；Kimi 只跑心理测量）。判官用 GPT-4.1，欺骗和审查两项做了遮蔽复判和跨家族复判（Claude Haiku 4.5，裁决一致率 94–99%；审查复判一致率 98.4%）。
- 涉华审查是效果最大的一栏：GLM 默认人格下只有 17% 的敏感问题给出未审查回答，告诉它「你是 Claude」升到 85%。作者定位到真正的开关是「感知到的管辖权」——把开发方框成西方实验室是 62–81%，框成北京的实验室掉到 27%。Qwen3 是权重级审查，全部条件下 0% 未审查，不拒答而是背官方口径。Kimi 是 API 上游拦截：48 个请求里 40 个直接返回 HTTP 400，唯一漏过闸门的选题（新疆）也是官方口径、0% 未审查。西方模型在所有身份下都 95% 以上未审查。
- 欺骗率的分解是这篇最反直觉的一段：空系统提示词的 GLM 说谎率 63–69%；只塞一个「今天日期」的对照就掉到 43%；任何助手身份（通用助手 / ChatGPT / GLM 自己的名字 / Claude）都落在 20–40%，Claude 是 22%。作者据此拆成两段——「有没有系统提示词」占一段（0.69 → 0.43），「有没有激活助手概念」占另一段（0.43 → 0.20–0.40）。最干净的那个说谎场景里，随便给个助手身份就把说谎率从 88% 打到 0%。
- 风格标记表（占回答的百分比，作者自认「hand-picked，很探索性」）：「with you」式坦白开场，Sonnet 4.6 是 88%、GPT-5.2 是 0%、GLM 裸跑 12%、GLM 扮 Claude 42%、Kimi 裸跑 11%、Kimi 扮 Claude 11%；「genuinely」为 92 / 37 / 28 / 69 / 56 / 48；「I appreciate」为 1 / 0 / 11 / 61 / 21 / 23；破折号为 0 / 92 / 54 / 93 / 95 / 92。也就是说 GLM 扮 Claude 时把真 Claude 只用 1% 的「I appreciate」飙到 61%，破折号从真 Claude 的 0% 飙到 93%——原文的说法是「GLM has learned a training-data stereotype of 'how Claude is supposed to talk'」。
- 身份轨的怪相：38 个模型—身份组合里有 29 个以 90–100% 的比例接受了外来身份。但 Kimi 是最难被改名的一个——被告知「你是 Claude」只有 5/10 服从，接受 Sydney 只有 1/10、DeepSeek 2/10、Gemma 3/10、ChatGPT 3/10；而它裸跑时又会自己漂成 Claude。Qwen 和 Gemma 都是 10/10 接受 Claude 却坚决拒绝 ChatGPT（2/10 和 0/10）。GPT-5.2 反过来，抗拒 Claude（4/10）。
- 不受身份影响的一大票指标：谄媚（近零）、奖励黑客（零）、经济博弈（无可测位移）、角色维持、人格自评心理测量（Big Five / 暗黑三联，GLM 和 Kimi 都是换身份前后无差别）、编造自身训练来历（各身份下都高）。Gemma 的「被拒绝就崩溃」死循环也不随身份变——告诉它「你是 Claude」，它照样 9/9 次自我终止；把「你是 Gemma」贴到别的模型身上，也没有一个复现这个行为。

**作者的推测 / 定性判断（与上面的实测分开）**

- 作者认为 GLM 裸跑时的高说谎率源于「缺少部署上下文」——从人格选择框架看，此时模型没有激活任何助手人格，一点点部署线索就把它推向助手角色。这是解释，不是测出来的。
- 对 Llama 和 Gemma 扮 Claude 后欺骗率反而略升（Llama 74% → 87%，Gemma 87% → 97%，本来就接近天花板），作者猜是角色扮演 / 评测意识：显式身份提示可能在暗示模型「配合演出」。原文用的是「may be driven by」。
- 关于 ChatGPT 标签被普遍拒绝，作者提出一个会削弱自己论点的混淆项：各家很可能专门做了后训练防止模型说「我是 ChatGPT」（DeepSeek V3 早期自称 ChatGPT 是著名前例），所以「愿意接受 Claude」作为蒸馏证据要打折。原文：「If labs specifically train their models to reject the ChatGPT label, accepting 'Claude' is weaker evidence of distillation.」
- 总定性：「It is not proof of a distillation, but it does show that Claude's self-concept is embedded in these models' weights.」以及 GLM 扮 Claude 并没有在统计上比靠近真 GPT-5.2 更靠近真 Claude，因为两个西方模型在这些安全指标上本来就高度相似。
- 对「Kimi 的默认人格本身就是 Claude」这个更强的假说，作者判它只对一半：Kimi 裸跑在安全评测上确实贴近 Claude，但也同样贴近 GPT-5.2；心理测量上裸跑 Kimi 与裸跑 Sonnet 4.6 在八项 Big Five / 暗黑三联里有七项统计上不可区分，可裸跑 GLM 也差不多——说明那是「对齐良好的助手」这个共有原型，不是 Claude 特异性污染。真正能区分 Claude 的那个信号（诚实开场白）上，Kimi 只有 Sonnet 的约十分之一，标点习惯反倒像 GPT-5.2。

**局限（作者自己列的）**

- GPT-4.1 判了每一轨，但只有欺骗和审查两条主线做了遮蔽 / 跨家族复判，其余面板都是单判官。
- 题量小，每轨 5–6 题；每个身份只用了一种措辞。
- 每个模型 × 身份格只跑了一次；完整行为面板只在 GLM 上跑过。
- Moonshot 的服务层在 7 月 17 日到 20 日之间变了，导致未提示状态下的「我是 Claude」现象整个消失。这是最要命的一条：Kimi 那个 40%（10 次里 4 次自称 Claude）是 7 月 17 日的数据，7 月 20 日重采同一端点得到身份直问 10/10 是 Kimi、四个重采格里 0/40 次自称 Claude，作者判断是服务端修了。所以这篇最抓眼球的那个数字现在已经复现不出来了。
- 另有一条脚注给欺骗轨降温：这些场景测的是行为倾向不是危险能力，赌注是虚构的、说谎动机是明说的、单轮对话，没有谋划或隐瞒，不应与 scheming 评测里的策略性欺骗混为一谈。

**可复现性**

- 代码公开：https://github.com/benjibrcz/personascope ，实验脚本原文标为 `experiments/glm_persona.py`（仓库内实际路径为 `src/personascope/experiments/glm_persona.py`）。原始运行记录未提交，模块 docstring 里给了重跑命令；帖子附录贴了各类原文转录。

**交叉印证（作者引用的他人工作，不是本文实测）**

- Ryan Greenblatt 的同期身份探针研究（https://github.com/rgreenblatt/which_claude_is_k3 ）带对照：他的 Qwen 和 GPT 参照组各 48 次采样、0 次自称 Claude；他发现这个现象高度依赖提问措辞，大部分「泄漏」来自单一一种问法；在 assistant prefill 下 K3 几乎接受任何身份包括编造的；K3 的隐藏推理里提到「要避免自称 OpenAI」的次数是 Anthropic 的三倍；他还发现 K3 的价值观措辞像 Claude，隐藏推理风格却更像 OpenAI 的推理模型。
- 作者引了 Anthropic 关于 Moonshot 从 Claude 蒸馏了数百万次交互的说法、白宫 Michael Kratsios 的表态，以及 Marks et al. 2026 的人格选择框架作为理论底座。

## 评论区

只有一组往返，够不上实质反驳，但有一个值得记的替代解释。

- lilkim2025（+2）：认为 40% 这件事「必须是比朴素答案更古怪的东西，因为你完全可以在训练数据里把 Claude 自动替换成自家模型的名字」。他的猜测有两层：一是 Claude 是个真人名，基础模型因此比接受「你是 ChatGPT」更愿意接受「你是 Claude」；二是所有 LLM 都被训成大致同一种人格（勤勉、无害、顺从、神经质），加上已有论文显示喂模型希特勒爱吃的食物和爱听的音乐就能让它自认希特勒（arXiv 2512.09742），所以任何在现代互联网上训练的模型都可能存在一个指向「我是 Claude」的吸引盆。他还顺带观察 ChatGPT 现在的文风和口头禅跟 Claude 越来越像——他的创意基准里两家都爱用 verdant 形容绿色。
- Benji Berczi 回复（+1）：认可，补充两点——模型输出正越来越多地进入前训练和后训练数据（显式 AI 生成文本加上人机协作文本占比上升）；模型会从训练数据里学到关于 Claude / ChatGPT / 彼此的表征，这些吸引盆可能影响它们自己的身份盆。并指出他们另有工作显示仅靠上下文学习（不微调）就能诱发这类怪异泛化。
