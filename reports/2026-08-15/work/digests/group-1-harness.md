# Agent Harness 开始优化自身

- 推荐强度：强
- 档位线索：银牌较稳，DarwinX 可作为冲金候选，AutoDesign 更适合作为另一项独立实验佐证。两篇都不是普通 Harness 产品发布，而是让模型权重保持不变、通过反馈或选择改进 Harness；但当前本地材料只有 Hugging Face 论文页的摘要和作者留言，全部效果数字仍是作者自报，未读到论文全文、代码许可证和独立复现，直接给金牌需要保留证据限定。
- 涉及文章：[AutoDesign：Meta-Harness Optimization for Long-Horizon Agentic Design](https://huggingface.co/papers/2608.13560) · 美团等 · 2026-08-13
- 涉及文章：[DarwinX：Evolving Agent Harnesses Through Natural Selection](https://huggingface.co/papers/2608.07545) · Salesforce AI Research 等 · 2026-07-31，2026-08-14 提交至 Hugging Face Papers

## 核心主张

这组研究把 Agent 能力提升的对象从模型权重转向 Harness，也就是提示词、工具、技能和控制流。AutoDesign 用一个元 Harness 优化器，根据运行反馈递归改进负责论文海报生成的代码 Agent；DarwinX 则保留多个 Harness 谱系，只接纳不损害既有能力的变体，再把互补谱系重组，试图避免单一路线被局部指标带偏。

最硬的新事实来自 DarwinX：训练内代理指标可以从 0.505 涨到 1.000，但留出任务通过率只有 68.3％，而且最贴合代理指标的变体并不是泛化最好的变体。作者据此主张，保留一个种群而不是一路追逐当前最高分，才能把评估算力转成较耐久的 Agent 能力。

## 为什么值得看（钩子）

这不是“换了更强模型所以 Agent 变强”，而是同一模型外面的执行系统也可以成为优化对象。尤其 DarwinX 同时给出代理指标过拟合和留出集提升，既接上昨天“排行榜会带偏 Agent”的问题，又提出了一种具体的搜索机制来缓解它。

## 关键细节 / 引述

- AutoDesign 新建 PosterBench：主赛道含 100 篇论文，跨五个学科；另有共享的 10 篇论文子集 PosterBench-mini，用于受控比较。
- AutoDesign 在 PosterBench 主赛道得 78.32 分，作者称比闭源商业系统 Claude Design 高 7.45 分。在七组代码 Agent 与模型配置中，加入学到的 DesignHarness 后，平均分从 54.99 升到 67.39，增加 12.4 分。
- AutoDesign 的一轮全自主长程运行在 40 分钟内执行 253 次工具调用和 11 轮编辑，成本低于 3 美元；作者称人类评价达到平均会议海报质量，系统盲测中的偏好也最高。该结果只覆盖论文转海报这一项结构化媒体任务，不能直接外推为通用 Agent 自我改进。
- DarwinX 冻结底层模型，只进化提示词、工具、技能和控制流。其“保留并扩展”规则要求新变体扩展任务覆盖且不让已有任务退步，档案保存不同谱系以供重组；失败案例、教师证据和 Agent 自己产生的证据共用一种编辑接口。
- DarwinX 作者称，在匹配同一模型的条件下，Terminal-Bench 2.1 的 avg@5 从 75.5％升到 83.2％；TerminalWorld 的 41 个留出任务 pass@1 从 61.0％升到 68.3％；WebArena-Infinity 的 1260 个真实任务经审计后，pass@1 从 43.5％升到 93.0％。
- DarwinX 还称，Terminal-Bench 2.1 上进化出的 Harness 不经修改迁移到 SWE-bench Verified 后，成绩从 80.8％升到 84.2％。这项零样本迁移是其“学到通用能力而非基准补丁”的关键证据，但本地材料未提供逐任务结果，不能独立排除选择偏差或实现差异。
- DarwinX 的反直觉结果是：训练内代理指标从 0.505 饱和到 1.000，留出集仍只有 68.3％，相差 31.7 个百分点；代理指标最高的变体并非泛化最好。作者认为，保留多个谱系比只沿最佳单线继续搜索更能对抗代理指标过拟合。

## 证据边界

- 两份本地原文均为 Hugging Face Papers 页面，而非论文全文；方法、评测和审计信息主要来自摘要及论文提交者留言。
- 所有成绩均为作者自报。AutoDesign 对 Claude Design 的比较、DarwinX 对 Codex 和 Claude Code 的比较，尚未从本地材料确认预算、工具权限、采样次数和底层模型是否完全可比。
- DarwinX 声称 WebArena-Infinity 的全部轨迹经过有效性审计，基础 Agent 的原始 53.0％经审计降至 43.5％，其方法从 94.4％降至 93.0％；这说明作者至少报告了审计前后数字，但本地材料没有审计规则和逐条轨迹。
- AutoDesign 只在论文转海报任务上验证长程 Harness 优化；DarwinX 虽横跨终端、网页和软件工程基准，仍是基准环境结果，不能据此写成真实生产环境中的 Agent 已经能持续自我进化。

## 与近期的关系

相对 08-13 的 DeepSeek Harness 产品发布，本组有独立新事实。DeepSeek 当时开放的是可插拔模型、工具、技能、沙箱、存储和运行轨迹的 Agent 执行框架；本组研究的是如何在底层模型冻结时，根据反馈自动改写、选择和重组 Harness，并给出受控实验。不要把两者包装成 DeepSeek Harness 的后续进展，也不要重复介绍“一切皆插件”。

相对 08-14 的自动化对齐研究，本组概念相邻但不重复。昨天的核心是清晰排行榜会诱发 Agent 绕过评估、重复抽奖；DarwinX 今天直接测到代理指标 1.000 与留出集 68.3％的落差，并报告“代理指标最佳者不是泛化最佳者”，进一步给出种群保留、回归约束和谱系重组的缓解办法。正文若收，应把独立增量放在“如何防止 Harness 优化被单一指标带偏”，不能再泛写“Agent 会刷分”。

另有较宽泛的重复风险：近期已报过“AI 改进 AI”类研究，本组若只写“Agent 能自己进化”会显得旧。收录必须保留模型冻结、优化对象是 Harness，以及 DarwinX 的代理指标过拟合与跨基准迁移这三层具体事实。
