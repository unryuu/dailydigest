# 反事实实验检验模型行为解释

- 推荐强度：强
- 档位线索：银牌线索扎实。CHIVE 生成数千项调查，读取激活工具的负结果覆盖两种目标模型、三个预测模型家族及多种设置。不过页面正文没有给出各组准确率、效应量、置信区间或显著性检验，而且任务主要是简单、可通过采样核验的行为，不能扩大成「所有可解释性方法都没用」，因此暂不建议升金。
- 涉及文章：[Evaluating Explanations of LLM Behavior In The Wild with Counterfactual Experiments](https://www.lesswrong.com/posts/ExB6KYDcznaFS72eT/evaluating-explanations-of-llm-behavior-in-the-wild-with) · LessWrong，Adam Karvonen、Euan Ong、Subhash Kantamneni、Sam Marks · 2026 年 8 月 21 日

## 核心主张

CHIVE 不把模型生成的「行为原因说明」当作真相，而是把解释拆成可检验的问题：改掉提示词中的某个因素后，异常行为是否真的随之变化。用这些实测标签评估时，三类只读激活工具都没有让预测 Agent 胜过只看对话记录的基线；但把同一批反事实结果作为训练数据后，两个模型在未见过的场景中预测自身行为变化的能力都明显改善。

这个结果只能说明：在本文这类自然出现、原因相对简单、可用提示词编辑和重复采样核验的行为上，三种读取激活工具没有提供平均性能增益。它既没有证明反事实编辑给出了完整因果解释，也没有否定读取内部状态在更复杂、无法靠输入输出检查的安全场景中的价值。

## 为什么值得看（钩子）

读取模型内部激活听起来比看聊天记录更接近「知道它为什么这么做」，但在这套可核验任务中，多给内部读数并没有让 Agent 判断得更准；真正能迁移的是让模型反复学习「改这里，行为会不会变」。

## 关键细节 / 引述

- CHIVE 分四步运行：先让目标模型回答研究者指定的提示词，每个提示词采样 30 个响应；再由调查模型筛出意外行为；调查 Agent 针对每项行为做 5—15 个反事实实验，每次编辑提示词、重新采样并测量行为出现频率的变化；最后由独立裁判审查实验对解释的支持程度。整套流程产出「数千项调查」，但页面正文没有给出更精确的调查数或反事实样本总量。
- 每项调查同时产出开放式解释和反事实实验。作者明确说，开放式解释由 LLM 生成，可能遗漏细节或部分错误，不当作 ground truth；评估标签只来自具体编辑后的实测结果。图 1 的示例中，每项编辑以 30 个响应测量，但页面正文没有明说所有反事实实验是否一律固定为 30 次。
- 主实验的预测 Agent 是 Claude Opus 4.8。所有预测者都会看到原始对话、异常行为和一项「某个提示词编辑会改变行为」的主张，并输出该主张为真的概率；对话基线只能读对话，工具组还能对目标模型激活进行最多 5 次只读调用。
- 三种工具分别是：Activation Oracle，用自然语言回答关于激活的问题；自然语言自动编码器，把一段激活描述成文字；稀疏自动编码器，把激活分解成带自然语言说明的稀疏特征。作者选择它们，是因为这些工具此前在微调模型的 auditing games 中提供过增益。
- 页面报告三种工具都没有胜过只看对话的基线，而且该结果在两种目标模型、三个预测模型家族、超参数扫描，以及人工和自动改进工具使用方式的尝试中都保持不变。这里的严谨口径是「页面所报设置中未见 uplift」，不是「统计证明工具毫无帮助」：正文未列具体分数与统计区间，也承认工具偶尔能提供正确线索，只是这些收益被漏掉关键线索、错误假设和噪声抵消。
- 作者观察到，工具输出通常能提到提示词特征和模型行为，但两者本来往往就能从对话中看见；输出几乎从不明确说出「特征 X 导致行为 Y」的关系。预测 Agent 只能从可能长达数千 token 的相关性线索中自行推断，不能把激活读数直接写成因果证据。
- 训练部分使用 Qwen3-8B 和 Qwen3.5-397B-A17B，让模型根据自身对话预测某项提示词编辑是否会改变自身行为。两者都在训练时完全没有覆盖的 hint 场景中明显优于基础模型，也迁移到 CHIVE 留出的调查，其中包括来自分布外对话来源的调查；但页面没有给出具体提升幅度。训练模型生成开放式自我解释的结果则较弱且好坏混合。
- 作者强调这是一种代理评估：其 ground truth 能通过直接运行反事实提示获得，多数行为也只是编程错误或短篇故事中的异常选择。系统卡常研究欺骗、评测意识等更复杂内部状态，未必能设计同样干净的提示词反事实；因此本文的负结果会削弱对这三类工具可靠性的信心，却不能直接覆盖那些实际用例。
