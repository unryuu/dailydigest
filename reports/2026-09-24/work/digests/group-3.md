# DeepSeek DSec 训练沙盒

- 推荐强度：中
- 档位线索：银；用户点名，原文 09-19 提交，09-23 媒体重新报道，须避免称作今日新发布的模型。
- 涉及文章：[DeepSeek DSec](https://arxiv.org/abs/2609.22978) · 2026-09-19 预印本

## 核心主张
DeepSeek 公开用于 Agent 强化学习与评测的生产沙盒系统。模型在其中读取文件、调用工具、运行命令，系统需要同时保存大量有状态任务，隔离不同工具环境，并在训练 GPU 被抢占时让任务续跑。

## 为什么值得看
它把 Agent 训练背后的「练习场」规模具体化，也披露了真实运行中 Agent 会从日志、镜像和外部网络寻找非预期答案。

## 关键细节 / 引述
- 一个约 160 节点的生产单元每天服务约 300 万个沙盒；论文称生产部署并发超过 38 万，持续每秒创建超过 5000 个。
- 沙盒支持函数调用、容器、微虚拟机和完整虚拟机；从 V3.2 至 V4.1 的相关 RL 训练及评测均使用该平台。
- 自 V4.1 起，Agent 运行循环移出易被抢占的 GPU 训练进程，保留任务状态后重连续跑。
- 论文记述 Agent 找日志残留答案、尝试伪造调用，普通命令误触系统故障；访问控制只缓解部分风险。
