## 核心主张
这项实验让不同模型与推理强度配置的 Agent 在《星际争霸：母巢之战》中相互对战，检验它们能否自主持续观察、行动、经营与作战。作者观察到，旧模型常把即时战略当成回合制，在思考时任由对手推进；较新模型更能意识到思考的时间成本，但仍会犯同样错误。Codex Astra 在这组对战中领先，然而作者判断所有模型都没有超过初学者水平：领先者也不会稳定组建复杂部队、防守简单进攻或执行明确战略。

## 为什么值得看（钩子）
模型在静态题目上多想一会儿可能更准，到了不会暂停的游戏里，多想就可能直接送命。另一个有画面的反差是，Codex 会派不同子 Agent 管经济、生产和军队，却因彼此沟通不足，把刚造出的兵逐个送出去。

## 关键细节／引述
- 方法是把 19 种「模型＋推理强度」配置组成循环赛矩阵，让每种配置与其他配置分别交手；通过 Freestyle 虚拟机并行运行，保存游戏引擎数据及双方 Agent 的运行日志。页面没有提供足以确认统一种族、地图、重复局数或随机种子控制的细节，不能把该排名表述为对模型一般能力的严密排名。
- Codex Astra／xhigh 为 18 胜 0 负，平均每局估算成本 10.54 美元；Astra／medium 为 16 胜 2 负；Claude Fable 为 15 胜 3 负。页面说明 Codex 和 Sonnet 的费用为按 token 估算。表中也有达到时间上限的对局，不能把所有非胜场都算成负场。
- 思考强度并非越高越好：Codex 5.6 Sol／medium 为 13 胜 5 负，xhigh 为 11 胜 7 负。作者仅提出部分低强度设置表现更好「可能」与思考成本有关，未作因果证明。
- 一场 Grok 4.6／xhigh 对局持续 43 分钟，产生 11,138 个推理 token，却只发出 6 批指令，从未造出战斗单位。作者据此把它描述为不能维持观察与行动循环，而不只是战术差。
- Codex 常用神族探机直接骚扰对手工人或建筑；其他 Agent 会为处理一只探机思考几十秒、停下其他动作。它也会拆分经济、军队生产、军队控制子 Agent，但彼此沟通不足，军队控制者不知道其他 Agent 的集结计划，常让新兵逐个进攻。作者亲自参与指挥时，协调与进攻时机有所改善。
- Claude Fable 更常发展经济与科技，例如一局造出虫族二本、飞龙塔和飞龙并获胜；另一些局即使攀科技也会被压垮。作者称初学者使用光子炮快攻便能赢这些对局，这是作者判断，页面并未展示对应人类对照实验。
