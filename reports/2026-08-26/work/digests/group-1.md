# DeepSeek 高 API 毛利率背后是近十倍基础设施投入

- 推荐强度: 强
- 档位线索: 够金。收入、毛利率、亏损和算力投入形成完整商业闭环，但全部未公开财务数字都要保留匿名信源限定；融资与上市只能写计划。
- 涉及文章: [DeepSeek’s Revenue Reaches $70 Million as of July, Tenfold Jump from 2025](https://www.theinformation.com/articles/deepseeks-revenue-reaches-70-million-july-tenfold-jump-2025) · The Information · 2026-08-25 23:50 PDT

## 核心主张

据两名了解公司财务数据的人士，DeepSeek 今年前七个月收入约 4.75 亿元人民币，约为 2025 全年的十倍；同期净亏损约 7.15 亿元，已经低于去年全年的 9.35 亿元。它的 API 业务据称已有 82.9％毛利率，但支撑增长的基础设施投入也从去年约 12 亿元放大到今年前七个月约 110 亿元。

公司六月完成首轮 500 亿元融资后，很快启动第二轮融资讨论，目标仍是募资 500 亿元、估值 5000 亿元，并聘请投行准备明年在上海上市。这些都还是讨论或计划，不能写成已经完成。

## 为什么值得看（钩子）

DeepSeek 不再只是低价开放模型的能力故事：它开始显出一门高 API 毛利率生意的轮廓，同时也暴露出算力支出随收入高速扩张。

## 关键细节 / 引述

- 前七个月收入约 4.75 亿元，约为 2025 全年收入的十倍；净亏损约 7.15 亿元，2025 全年为 9.35 亿元。
- 前七个月整体毛利率为 44.6％，API 业务毛利率为 82.9％；报道把较高毛利归因于推理基础设施效率和更少芯片用量。
- 前七个月基础设施相关支出约 110 亿元，包括服务器租赁、芯片和其他计算设备；2025 全年约 12 亿元。
- 公司近期上调 API 价格，但旗舰模型输出价格仍低于报道列举的 Kimi K3 和 Claude Opus 5。
- 第二轮融资目标募资 500 亿元、估值 5000 亿元；明年上海上市是准备方向，不是确定结果。
- DeepSeek 未回应报道的置评请求，财务数字此前没有公开披露。
