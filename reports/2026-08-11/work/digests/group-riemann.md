# Claude 研究黎曼猜想取得进展，推进了下界

- 推荐强度: 强
- 档位线索: 够金牌线索。结果本身有明确、可量化的推进，且人机协作过程罕见地完整；但正文必须准确写成“提高与黎曼猜想相关的已知下界”，不能写成解决或接近解决黎曼猜想，也应保留结果尚待更广泛独立检验的审慎口径。
- 涉及文章: [Learning more about Claude's mathematical capabilities](https://www.anthropic.com/research/riemann-zeta) · Anthropic · 2026年8月10日

## 核心主张
Anthropic 称，一个尚未发布的 Claude 研究版本在尝试攻克黎曼猜想时并未成功，却意外推进了一个相关问题：把已知能证明落在临界线上的黎曼 ζ 函数零点比例下界，从 41.6％提高到 67.2％。这不是对黎曼猜想本身的证明，也不代表 67.2％的零点才位于临界线上，而是人类目前能够证明的最低比例提高了。结果大量借助既有数学工作；Anthropic 也明确表示，不认为 Claude 使用的技术会导向黎曼猜想的证明。

## 为什么值得看（钩子）
最值得看的不只是数字，而是一次以失败为起点的自动研究流程：模型先提出 650 个无效想法，随后组织约 60 个子 Agent 深挖、互审、找反例、查重并形式化，最后留下了一个与原任务不同但可验证的新结果。

## 关键细节 / 引述
- 新结果针对的是“满足黎曼猜想、即位于临界线上的 ζ 函数零点所占比例”的已知下界，数字由 41.6％提高到 67.2％；原文明确说 Claude 没有解决黎曼猜想。
- Anthropic 对模型身份的唯一公开表述是“尚未发布的 Claude 研究版本”，没有给出正式型号，因此不能写成 Claude Fable 5 或其他具体产品名。
- 结果结合了 Baluyot、Goldston、Suriajaya、Turnage-Butterbaugh 的一系列研究与 Bombieri 2000 年论文。Anthropic 将关键一步概括为：在同一函数空间里同时处理临界线上与线外零点对应的正定、负定子空间，并允许二次型非对角化。
- 两名 Anthropic 数学家 Levent Alpöge 和 Ralph Furman 检查了 Claude 的工作，理解新结果及其与既有研究的关系；Anthropic 另称内部两名数学家研究并验证了论文。外部专家 Brian Conrey 和 Dan Goldston 在短时间内“examined the paper”，原文没有把他们的动作明确写成正式同行评审或独立验证。
- Claude 还与 Anthropic 员工 Eric Easley 一起产出了 Lean 形式化证明，且该形式化结果通过标准验证工具 comparator。模型在定稿前还让不同子 Agent 审查证明、寻找反例、下载 54 篇 arXiv 论文检查是否已有相同发现，并从头独立重证结果。
- 整个发现发生在两次 Claude Code 会话中，共消耗约 3100 万输出 token。第一次提出并尝试了 650 个想法，全部失败；第二次用一天半协调约 60 个 Claude 子 Agent，运行 2400 条 shell 命令并写了数百个 Python 脚本。60 个子 Agent 中，2 个发展出关键数学想法，13 个提供思路，30 个尝试新方向但失败，13 个负责验证，2 个协助撰写初稿。
- 发起者 Jarred Sumner 是 Anthropic 员工，但不是数学家。他最初只要求 Claude “认真尝试一下”黎曼猜想，之后的人工输入主要是“继续”“相信自己”一类鼓励；找到结果后，Claude 主动建议由人类数论专家验证。

## 与近期的关系
从本文自身看，这是 2026年8月10日发布的新研究结果，不是对旧模型数学基准的常规升级稿；它把“模型会解题”的叙事推进到“模型能组织研究流程并产生相关新结果”。与近期日报是否重复仍需调度结合历史记录确认；主题层面可能与此前 Claude 发现密码学弱点、反驳 Jacobian 猜想等“AI 辅助科研”案例相邻，但本条的黎曼 ζ 函数下界、形式化证明和 60 个子 Agent 流程均构成明确新信息。
