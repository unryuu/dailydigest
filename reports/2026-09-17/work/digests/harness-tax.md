# 同一个模型，换个编程 Agent 外壳，价格能差到五倍

- 推荐强度：强
- 档位线索：够银。亮点不是宣布某个外壳“最好”，而是把模型与外壳拆开评测：在两个公开基准里，成功率常常接近，成本却能相差数倍；最简的 Pi 只靠四个工具也能站上帕累托前沿。
- 涉及文章：[HarnessTax: How Much Does the Harness Matter for Coding Agents?](https://harnesstax.github.io/) · UC Berkeley／Arena · 2026-09-16

## 核心主张

研究对七个模型与 Claude Code、Codex CLI、Pi 三个编程 Agent 外壳组成的二十一个组合做了对比，在 SWE-bench Lite 与 Terminal-Bench 2.0 各随机抽三十个任务、每个组合每题跑三次。结果显示，在这两套公开基准上，外壳对成功率的平均影响有限，却会显著改变 token 成本；同一模型取得相近成功率，价格最多可差五倍。默认选择模型供应商自己的外壳，也没有稳定地给出最佳组合。

## 为什么值得看（钩子）

大家买编程 Agent 时往往只比较模型名，真正悄悄累积账单的可能是模型外面那层提示词、工具定义和执行循环。最朴素的四工具外壳不但没有明显掉队，有时还更便宜、更准。

## 关键细节／引述

- 每个模型—外壳组合在每个基准使用同一批随机抽取的三十个任务，每题运行三次，每次最多一百个 Agent 回合；成功与否由基准官方评估器判断。
- 成本按 2026 年 9 月 1 日固定的直接 API 价目表估算，同一模型跨外壳使用同一价格。SWE-bench Lite 禁止任务容器访问外网，也关掉 Claude Code 与 Codex 的默认网页工具。
- Claude Fable 5 在 SWE-bench Lite 中，Claude Code、Codex 与 Pi 的成功率分别为 97.8％、96.7％ 与 96.7％；Claude Code 平均成本约 1.33 美元，Pi 约 0.67 美元。
- 按共同模型的成本比几何平均，Claude Code 在 SWE-bench Lite 上约为 Pi 的两倍、Codex 的 1.6 倍；在 Terminal-Bench 2.0 上约为 Pi 的 1.5 倍。外壳对成功率的平均影响在前者为正负 2％ 以内，在后者约为正负 5％ 以内。
- Pi 只提供 read、write、edit 与 bash 四种工具，却在两个基准都达到帕累托前沿。Claude Code 的首次主模型调用初始上下文，七个模型平均都超过 Pi 的十倍；但总成本还受缓存、输出 token 与后续调用影响。
- 在六个 Anthropic／OpenAI 模型乘两个基准的十二次比较中，九次由非自家外壳取得观察到的最高成功率。例如 GPT-5.6 Sol 在 Terminal-Bench 2.0 中用 Pi 成功率 83.3％、平均 0.42 美元，用 Codex 则是 78.9％、0.76 美元。

## 必要限定

- 结论仅来自两个公开基准，模型可能在训练中见过其中任务；真实代码库、跨会话工作、人工反馈与联网工具下的结果可能不同。
- 每个基准只有三十个独立任务，虽重复三次并用一万次 bootstrap 估算置信区间，仍不足以给所有工作负载排总榜。
- 各外壳的“回合”和“高努力”定义不同，不能把每回合成本差完全归因于初始提示长度；研究团队也尚未在页面发布完整 profiling traces。

## 与近期的关系

近期多次写过推理价格、模型路由与企业上下文成本，但本次首次直接把同一模型跨三种编程 Agent 外壳对比。正文不要泛化成“外壳不影响能力”，准确口径是这两个公开基准上的平均成功率差较小、成本差更大。
