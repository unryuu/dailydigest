# OpenAI 把广告点击后的对话也变成广告位

- 推荐强度：中
- 档位线索：够银。Sponsored Agents 是新的广告产品形态，不只是广告后台加 AI；同时必须把它与 ChatGPT 的独立回答、用户原始对话明确分开，避免写成品牌已经能混入普通答案。
- 涉及文章：[Reimagining advertising with AI](https://openai.com/index/reimagining-advertising-with-ai/) · OpenAI · 2026-09-16

## 核心主张

OpenAI 正在美国与部分广告主测试 Sponsored Agents：用户点击 ChatGPT 中的广告后，可以进入一段有清晰标记、由商家赞助的独立对话，继续问产品尺寸、适配或保养等问题。OpenAI 同时让广告主用 ChatGPT Work 的自然语言提示创建、更新和分析广告活动，并把 ChatGPT Ads 接入 HubSpot 与 Shopify。广告不再只争一次点击，也开始接管点击后的咨询过程。

## 为什么值得看（钩子）

搜索广告把流量送到商家网页，Sponsored Agents 则试图让品牌在 ChatGPT 里继续陪用户做决定。真正值得盯的不是 AI 自动写文案，而是“独立回答”和“商家赞助对话”之间的边界能否长期清楚。

## 关键细节／引述

- Sponsored Agents 目前只与美国部分广告主测试；用户需要先看到并点击相关广告，再主动进入有明确标记的商家赞助对话。
- OpenAI 明确称，赞助对话与 ChatGPT 的独立回答不同，也与用户原先在 ChatGPT 发起的对话分开。官方材料没有说品牌可以直接付费改变普通回答。
- Ads Manager 插件允许广告主用自然语言创建、更新与分析广告活动，并从网站或 brief 生成活动、理解表现与获得后续建议。
- Ads Manager 还会根据落地页与活动目标建议文案和图片，广告主可先审阅与编辑；可选的文本定制功能会按对话语境调整现有标题和描述，并自动翻译到用户偏好的语言。
- HubSpot 用户从当日起可连接 ChatGPT Ads 账户，在 HubSpot 内创建广告、追踪表现与跟进线索；美国 Shopify 商家也可通过应用创建与管理活动，其他已有 ChatGPT Ads 的市场计划于 9 月 23 日开放。

## 必要限定

- 这是 OpenAI 自己的产品发布，没有独立效果数据、广告转化率或用户接受度；“更有帮助”是公司主张。
- 赞助 Agent 是点击广告后的可选独立体验，不能写成广告主已经能介入所有 ChatGPT 对话或改变普通回答。
- 文案与图片建议仍由广告主审核；动态文本定制需要广告主主动选择开启。

## 与近期的关系

八月底已经报道过 OpenAI 广告年化收入与商业化进度，本次不能再把重点放在广告收入规模。新增量是 Sponsored Agents 的交互形态、广告管理插件，以及 HubSpot／Shopify 的正式接入。
