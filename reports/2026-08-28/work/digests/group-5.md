# 最会独立完成任务的模型，未必最会辅助另一个执行者

## 核心主张

CentaurBench 把模型放进两种角色比较：一种是直接交付成果，另一种是先给标准化的较弱模型写指导文本，再由后者交付成果。两种模式的排名只有温和相关，自动完成任务的冠军在七项任务中的五项辅助评测里落败，说明“自己做得好”不是“能让另一个执行者做得更好”的可靠替代指标。更反直觉的是，辅助并不稳定产生正收益：三项任务中，不接受任何指导的较弱模型胜过了所有受辅助条件。

## 为什么值得看（钩子）

主流榜单大多奖励模型独立把活干完，但真实的人机协作和多 Agent 系统常要求一个强模型去指导另一个执行者；这项研究显示，选“最强选手”当“教练”可能恰好选错。它也给当前强化 Agent 自主能力的方向补了一条代价线索：自主能力进步，未必同步改善协作能力。

## 关键细节 / 引述

- 评测覆盖七项具有经济现实背景的工作任务；辅助模式下，候选模型只撰写指导文本，统一的较低能力 worker model 负责产出最终交付物，自动化模式下则由候选模型直接产出。
- 最终成果通过盲法成对比较，由采用任务专用评分标准的 LLM 裁判组评分；每种比较重复十轮。这里既没有真人执行者，也没有真人裁判，是外推到“帮助人类工作”时最重要的实验限定。
- 两种模式的模型排名只有“温和相关”；自动化模式的冠军在七项任务中的五项辅助评测里输掉。
- 三项任务中，无辅助的 worker model 排名高于全部受辅助条件；按平均表现计算，只有一个模型的指导胜过完全不给指导。
- 论文作者 Abhishek Nagaraj 将结论概括为：“最好的选手并不是最好的教练。”他进一步称，Opus 和 Sonnet 独立执行任务表现强，但提供辅助不强；GPT-5-Mini 在两个维度都强；Gemini 系列作为辅助者的相对表现好于作为自动执行者。
- Ethan Mollick 据此提醒，当前推动模型成为优秀 Agent 的压力，可能损害或至少忽略人类与 AI 协作所需要的能力；但论文实验本身没有直接测试真人，因此这句话应作为研究启示，而非已经由实验验证的人类效果。

## 与近期的关系

这不是又一张通用模型能力榜，而是把同一批模型按“自动执行”与“辅助执行者”拆成两张榜，给 Agent 和多 Agent 讨论补了一个新的评价维度。与近期强调自主 Agent 的报道在主题上相邻，因此存在轻度题材重复风险；不过“能力强的 Agent 未必是好教练”属于新的反向结论，不是旧事重炒。现有指定材料不足以核对历史日报是否出现过同一论文或同一 URL。
