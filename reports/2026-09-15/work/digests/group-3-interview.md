# OpenAI 把自动化 AI 研究列为首要目标

- 推荐强度：强
- 档位线索：可作为独家视角的主轴，与两篇递归自我改进论文合并。只取优先级、研究品味和多 Agent 训练，不再写近期已经反复报道的攻击事故与思维链监控。
- 涉及文章：[OpenAI’s ‘Top Priority’ for AI Agents is Automating AI Research, Says Noam Brown](https://www.theinformation.com/articles/openais-top-priority-ai-agents-automating-ai-research-says-noam-brown) · The Information · 2026-09-14 13:08 PDT

## 核心主张

OpenAI 研究员诺姆·布朗称，公司的第一优先级是让模型参与 AI 研究，实现递归式自我改进，而且明显高于其他方向。当前 Agent 已能大幅接手数据和代码质检，真正难点变成判断下一步最值得研究什么。

## 为什么值得看（钩子）

这次说法把 OpenAI 的能力路线明确排了顺序，也用一次三天对六年的失败说明自动化研究卡在哪里。

## 关键细节／引述

- 布朗说，如果给公司目标排序，递归式自我改进排第一，而且领先幅度很大；软件工程等方向同时能创造收入并帮助内部研究，因此更容易被优先投入。
- 他称 Agent 已能把研究员过去逐行完成的数据和代码质检做得好一百倍；他自己的日常工作像由五个 Codex 协作完成。
- 他让 Astra 在三天内重做自己花六年完成的扑克 AI 博士研究，模型反复钻进不重要的方向，没能完成；他把失败归为研究品味不足。
- OpenAI 的多 Agent 训练允许 Agent 互发任意消息，并学习何时委派、委派什么；不同 GPU 运行速度不一会让委派方无法确定对方能否及时交付，是训练难点之一。
