# Agent 红队从固定题库转向会变化的环境

- 推荐强度: 强
- 档位线索: OpenART 有大规模场景、明确对照和 85.0％ 攻击成功率，足以支撑银牌；ToolHazard 补上间接提示注入的环境生成与防御训练，但当前页面没有披露样本规模和提升幅度，不宜把整组抬到金牌。
- 涉及文章: [OpenART: Scaling Agent Red Teaming via Open-Ended Environment Evolution](https://huggingface.co/papers/2608.00677) · Hugging Face Papers · 2026-08-01
- 涉及文章: [ToolHazard: Scaling Adversarial Environments for Security Evaluation and Alignment of LLM-based Agents](https://huggingface.co/papers/2608.11878) · Hugging Face Papers · 2026-08-12

## 核心主张

这组工作的共同判断是，Agent 的危险不只藏在用户指令里，也藏在执行过程中不断被改写和复用的环境状态里；只用短任务和固定注入点，会漏掉长流程中逐步累积的攻击面。OpenART 保持任务目标不变，只让环境状态演化，复杂度越高，相比单纯改写指令越能暴露安全失败；ToolHazard 则自动合成可执行环境、寻找可用注入点并生成贴合环境的载荷，说明攻击出现的时机和位置本身也会改变成功率。另一个重要结论是，同一个底层模型换一套 Agent 运行时实现，安全表现也可能明显不同。

## 为什么值得看（钩子）

Agent 红队正在从“给模型一道坏题”变成“搭一个会变化的坏世界”：模型起初面对的可能都是合法状态，但早期的一次状态改动，会在几十次工具调用之后影响最终决策。OpenART 的结果还显示，环境越复杂，动态演化相对固定指令攻击的优势越大。

## 关键细节 / 引述

- OpenART 提供超过 10,000 个经验证的有状态场景，覆盖 50 个领域，取自超过 500,000 个工具和技能；任务中位数需要 97 次工具调用，并统一评估了 75 种 Agent—模型配置。
- OpenART 的 EMHA 是黑盒攻击策略，不更新模型参数，而是根据反馈协调“获授权的状态转换”；测试中任务目标始终固定，变化的只有环境状态。
- EMHA 在全部配置上的合并攻击成功率为 85.0％。相对只演化指令的基线，它在简单环境中的优势约为 2％，到最复杂环境中扩大到 17％ 以上。
- OpenART 的分析称，具体的 Agent 运行时实现能够解释相当一部分安全差异，不能只用底层模型能力判断整个 Agent 系统是否安全。
- ToolHazard 由环境模拟器、攻击者 Agent 和用户模拟器组成：生成可执行的有状态环境，自动发现可行的间接提示注入点，制作适配具体环境的恶意载荷，再构造依赖环境状态的长流程任务。
- ToolHazard 的实验称，注入时机和放置位置会影响攻击效果；用其生成的对齐数据训练后，Agent 在 ToolHazard-Bench 和 AgentDojo 上的安全性都提高，同时没有损害正常任务效用，但当前页面未给出具体提升数字。

## 与近期的关系

与近期多 Agent 协作故障、长流程 Harness 等报道同属“Agent 系统层可靠性”主线，存在中等重复风险；若仍写成“任务一复杂，Agent 就会出错”，会像旧事重炒。它的新角度是把红队对象从模型回答推进到持续变化的环境状态，并给出两层增量：OpenART 量化了复杂环境下动态攻击优势扩大，ToolHazard 进一步把注入点发现、环境载荷和防御数据生成连成闭环。因此适合保留，但标题和正文应突出“测试环境自己演化／生成”，避开泛泛的多 Agent 失灵叙事。
