# Google 发布 Gemini 3.7 Flash

- 推荐强度: 强
- 档位线索: 更适合银牌而非金牌。它是正式模型发布，编程、业务流程和价格都有明确变化，但仍是 Flash 系列三周内的迭代，全部效果数字来自官方评测。
- 涉及文章: [Introducing Gemini 3.7 Flash](https://deepmind.google/blog/introducing-gemini-3-7-flash) · Google · 2026-08-13

## 核心主张

Gemini 3.7 Flash 面向编程和 Agent 工作流，在 3.6 Flash 发布三周后继续提高编码、网页开发、复杂文档和业务自动化能力。年底前的介绍价为每百万输入 token 0.75 美元、输出 token 3.75 美元，Google 称这相当于 3.6 Flash 原始价格的一半。

## 为什么值得看（钩子）

这不是只换榜单数字：Google 同时把更新装进 Gemini Spark，并用明显降价推动长程 Agent 和企业工作流。

## 关键细节 / 引述

- FrontierCode 1.1 Main 从 34.4％升到 43.6％，DeepSWE v1.1 从 49.0％升到 65.3％。
- WebDev Arena Elo 从 1538 升到 1588；复杂文档基准 GDP.pdf 从 22.0％升到 34.0％。
- AutomationBench 从 17.0％升到 30.4％。
- 年底前介绍价为每百万输入 token 0.75 美元、输出 token 3.75 美元。
- Gemini Spark 当天开始换用 3.7 Flash；开发者也可通过 Gemini API、Google AI Studio 和 Android Studio 使用。

## 与近期的关系

近期连续出现 DeepSeek、Qwen、Grok 等模型发布，但这是 Google 自己的新版本和明确价格变化，不是同一事件。模型发布密度较高，因此不宜仅因榜单提升给金牌。
