# Jev 与 Minecraft 案例

值得进本期日报，建议银牌，把开放使用和游戏案例合为一条。核心价值是把长程规划、快速选择和具体执行拆开，让读者看见一种实际用法。不要把这次演示写成随机地图速通纪录或模型从零学会游戏。

Jev 是 TypeSafe AI 的决策模型。输入当前状态和问题，输出选项、评分或是非概率，供程序直接使用。它不负责写文章，当前只接收文本和结构化文本；在游戏里看到的是程序整理的坐标、背包与环境状态。官方标价每百万输入 token 为 0.042 美元，输出免费，发布文给出的响应范围是 70 至 500 毫秒。它保证输出遵守规定结构，仍可能选错；官方能力说明也列出了算术、多跳推理等短板。[官方介绍](https://typesafe.ai/blog/introducing-system-one-models-and-jev)；[模型卡](https://docs.typesafe.ai/models)。

开放使用的消息属实。09-15 发布文仍写早期访问、逐步放行排队用户，09-20 官方原帖已明确说向所有人开放、不再排队。X 网页读取403后，主 agent 从 X 自己的官方嵌入接口取得了原帖与作者信息，没有用独立教程站冒充官方公告。[官方原帖](https://x.com/typesafeai/status/2101786156572823624)。

截图也对应真实原帖。作者 Ronak Malde 报告耗时8分43秒，模型费为Jev 0.01美元、Astra 0.96美元。仓库README对应的 nether-final-08 记录为8分43.300秒，131次Jev决策、35次Astra调用。这里的约0.97美元是该轮模型调用费，开发、先前试跑和服务器不在这个口径里。代码公开了，但完整录像、世界存档和该轮日志保留在作者本地；本轮调查没有重跑游戏。[作者原帖](https://x.com/rronak_/status/2101544156757950697)；[作者仓库](https://github.com/rmalde/minecraft-agent)。

玩法是预选地图的生存模式、和平难度，路线预先勘测，坐标已提供，地图中有天然激活的末地传送门，因此省掉收集烈焰棒等流程。Astra给出当前目标，Jev从候选动作里挑下一步，Mineflayer负责寻路和具体操作；可读传感器还提供龙头位置。代码中的异步规划确实让Astra在后台更新目标时，Jev可以继续行动。8分43秒覆盖杀龙并到达出口的完成流程，不能直接拿来与随机地图、人类同等输入条件的纪录比较。

截图里“持续学习积累技能”不适合原样入稿。已读代码和开发记录体现了试跑后修改路线、动作与规则，以及当轮基于近期状态重做计划。它们没有展示Astra在这一轮里更新模型参数；模型和传统程序各自贡献多少，也没有通过同条件去掉Jev的实验拆开。日报用分工机制和带设置的成绩，就足以表达这件事。
