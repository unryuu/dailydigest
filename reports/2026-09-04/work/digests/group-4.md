# GPT-6 Astra 正式发布

- 推荐强度：强
- 档位线索：银牌。属于大版本正式发布，但 09-02 已报循环架构和 Critical 网络安全门槛，本期只写新产品能力、开放范围和价格。
- 涉及文章：[GPT-6 Astra: A new generation of intelligence](https://openai.com/index/gpt-6-astra/) · OpenAI · 2026-09-03

## 核心主张

OpenAI 正式发布 GPT-6 Astra，把重点放在直接操作电脑、完成多步骤专业工作和交付文档、表格、演示与软件。它先向少数机构开放，随后几天覆盖 ChatGPT Plus、Pro、Business、Enterprise、API、Azure 和 AWS Bedrock。

## 为什么值得看（钩子）

这次大版本不只回答问题，而是把浏览器、桌面软件、代码、研究和办公产物放进同一个执行模型，并把长期任务的上下文保存方式一并更新。

## 关键细节／引述

- Astra 能操作电脑填写表格、更新客户记录、安排日程、使用专业软件分析数据，并生成网站、文档、表格和演示。
- Codex 新增长任务记忆方式：模型可跨上下文窗口保留笔记，并搜索之前窗口里的要求和测试结果，减少多次压缩造成的信息丢失；目前可在配置中开启，之后会成为 Astra 默认功能。
- 在 Mind2Web 评测中，Astra 配合新版 Codex 执行框架的任务完成速度为 GPT-5.6 Sol 的 1.9 倍。
- 首批只向少数机构开放，随后几天覆盖 ChatGPT Plus、Pro、Business、Enterprise、OpenAI API、Azure 和 AWS Bedrock。
- Pro、Business 和 Enterprise 用户还会获得 Astra Pro；企业管理员默认需要主动开启。
- API 标准价格为每百万输入 token 10 美元、输出 token 50 美元；快速模式速度最高翻倍，价格也翻倍。
